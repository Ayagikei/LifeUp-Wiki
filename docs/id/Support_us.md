# Dukung kami

Dukungan Anda selalu kami hargai. ❤️

Dengan dukungan Anda, kami dapat meluangkan lebih banyak waktu untuk pengembangan dan mendapatkan lebih banyak sumber daya agar App semakin baik, seperti server yang lebih baik dan fitur baru.

Masih banyak ide yang ingin kami wujudkan.

## Untuk Semua Orang

### Bagikan Aplikasi

Membagikan dan merekomendasikan [App kami](https://play.google.com/store/apps/details?id=net.sarasarasa.lifeup) kepada teman juga sangat membantu.

### Beri rating / Kirim saran

Pertimbangkan untuk memberi rating kami di Google Play. ❤️

Saran selalu kami sambut.


### Buy me a coffee

Jika App benar-benar membantu Anda, pertimbangkan untuk mendukung kami dengan membeli kopi di halaman **About** di App.

Atau, merekomendasikan LifeUp kepada teman dan komunitas Anda juga cara yang bagus untuk mendukung kami!


## Penerjemah

Membantu terjemahan App juga sangat berarti. Saat ini kami memperkenalkan terjemahan berbantuan AI, tetapi tinjauan manusia tetap penting.

Proyek terjemahan kami dihosting di Crowdin: [LifeUp di Crowdin](https://crowdin.com/project/lifeup).

Jika Anda menemukan masalah terjemahan tertentu atau ingin berkontribusi pada bahasa baru, pertimbangkan untuk bergabung dengan proyek Crowdin kami atau hubungi kami langsung.


## API & Integrasi

LifeUp menyediakan berbagai API dan opsi integrasi. Kami sangat menyambut kreasi dan berbagi berbasis komunitas dari API ini!

Baik skrip kustom, integrasi desktop, atau cara baru berinteraksi dengan LifeUp, kontribusi Anda dapat memperluas ekosistem LifeUp.

Lihat [dokumentasi API](guide/api.md) kami untuk detail selengkapnya.
