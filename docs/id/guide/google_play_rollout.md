## ❓ FAQ: Mengapa rollout bertahap?

- Kami mulai dengan persentase kecil pengguna, lalu memperluas setelah stabilitas terkonfirmasi untuk mengurangi dampak bug tak terduga.
- Laporkan masalah apa pun selama rollout; kami akan memperbaiki dan menerbitkan ulang secepat mungkin.
- Build bertahap dapat menyertakan fitur terbaru sekaligus perilaku tak terduga sesekali. Versi ini dapat memakai label `alpha` / `beta` / `rc` dan dapat diperbarui lebih sering untuk mengirim perbaikan.
