## Batasi penggunaan untuk efek pengurangan Poin Pengalaman

Anda kini dapat mengaktifkan *Batasi Penggunaan* untuk efek pengurangan Poin Pengalaman.

Jika Anda tidak memiliki jumlah Poin Pengalaman yang cukup saat menggunakan Item, App akan melarang Anda
menggunakan Item tersebut.

Ini memberi efek menggunakan Poin Pengalaman sebagai sejenis mata uang.

## Log Rilis

**✨Fitur**

1. Mendukung Pencapaian dengan beberapa kondisi buka kunci
2. Detail Pencapaian mendukung melihat detail kondisi dan progres
3. Tag Tugas
4. Tugas berulang tanpa tenggat
5. Sembunyikan Item yang habis terjual atau pembeliannya dinonaktifkan
6. Saat mengatur efek pengurangan Poin Pengalaman untuk Item, opsional untuk membatasi penggunaan
7. Halaman Inventaris mendukung multi-pilih, pilih semua, dan pengembalian batch
8. Daftar Tugas default mendukung operasi arsip
9. Mendesain ulang beberapa halaman seperti pengaturan, Tanya Jawab, toolbar Toko, dan halaman tambah daftar
10. Mendesain ulang beberapa ikon di App (ikon kartu Tugas default, koin, Poin Pengalaman, ikon
    Pencapaian)
11. Penyimpanan gambar dipindah ke path privat eksternal App untuk mencegah penghapusan file tidak sengaja

**♻️Peningkatan**

1. Menambahkan tautan artikel [Konfigurasi Kompatibilitas] ke halaman pengaturan
2. Hitung mundur Pomodoro — operasi reset menambahkan dialog konfirmasi
3. Menambahkan deskripsi untuk pembekuan Tugas
4. Menambahkan deskripsi untuk sub-kategori Pencapaian
5. Dalam mode offline, menambahkan tombol keluar mode offline di halaman edit profil
6. Mengoptimalkan statistik Tugas plenty (negatif), mendukung tampilan jumlah penyerahan hari itu dan pelacakan Pencapaian
7. Mengoptimalkan kecepatan startup App
8. Ikon Pencapaian mendukung melihat gambar lebih besar
9. Menambahkan statistik suka (diterima) untuk Tugas acak
10. Mengoptimalkan interaksi pencarian secara terpadu
11. Saat memilih Item, beralih ke daftar kosong menampilkan layout kosong (bukan loading)
12. Halaman lihat gambar besar menyesuaikan pengaturan warna tema saat ini
13. Mengoptimalkan efek animasi saat tinggi popup Item dan Tugas terpilih berubah
14. Di pengaturan cadangan, "Hapus data lokal" juga mendukung menghapus file media
15. Menyatukan logika penyimpanan dan penghapusan file sementara untuk mengambil foto
16. Membedakan ikon Item default dan ikon yang gagal dimuat
17. Mengaktifkan pengaturan plenty independen untuk Tugas secara default
18. Mengoptimalkan refresh, logika animasi, dan kecepatan loading halaman Perasaan
19. Beberapa popup detail menambahkan tombol pintasan "pilih"
20. Saat saklar utama "efek suara" dan "getaran" di halaman pengaturan lanjutan
    dimatikan, instruksi terkait juga disediakan di pengaturan tomat
21. Optimasi pengurutan Pencapaian dan sub-kategori baru
22. Upgrade library dasar dan dependensi
23. Mengoptimalkan metode dan kecepatan perhitungan progres Pencapaian
24. Meningkatkan metode perhitungan "target (pengulangan) kali" agar mengikuti peningkatan statistik
    catatan riwayat, konsisten dengan jumlah kali di detail
25. Saat memasukkan jumlah koin dan jumlah pengulangan target, semua nilai saat ini akan
    otomatis dipilih
27. Mengoptimalkan prompt error saat konfigurasi WebDAV abnormal
28. Mengoptimalkan prompt error saat cadangan Google Drive abnormal
29. Kini mendukung memilih nama Tugas di halaman detail

**🐛Perbaikan**

1. Memperbaiki masalah bahwa set count memengaruhi Hadiah Tugas menjadi tidak valid setelah Tugas menjalankan
   logika pengulangan
2. Memperbaiki masalah pengurutan dan pengelompokan halaman Toko
3. Memperbaiki masalah abnormal halaman naik turun di Tugas acak dalam beberapa kasus
4. Memperbaiki masalah bahwa stat Pomodoro di halaman status tidak akurat setelah menggunakan
   timing positif dalam beberapa kasus
5. Memperbaiki masalah bahwa logika pengulangan Tugas tim kehilangan pengaturan tipe Tugas count
6. Memperbaiki masalah bahwa Tugas yang dipilih Tomat disorot saat memilih Tugas
   terkait kondisi Pencapaian
7. Memperbaiki masalah bahwa gambar Perasaan tidak disimpan secara independen dan masalah tampilan
8. Memperbaiki masalah bahwa prompt kegagalan mungkin muncul berulang saat login gagal
9. Beberapa kotak input khusus untuk Tugas, tim, dan subtugas baru seharusnya tidak mengizinkan input keyboard,
   yang dapat menyebabkan App crash
10. Mengoptimalkan cara menghitung jumlah penyelesaian Item tak terbatas di widget App,
    konsisten dengan di App
11. Memperbaiki masalah bahwa setelah ATM menyesuaikan suku bunga, bunga mungkin dihitung
    berdasarkan waktu terakumulasi dan suku bunga yang disesuaikan
12. Memperbaiki masalah bahwa Tugas beku mungkin masih ditampilkan di daftar pintar
13. Mengoptimalkan masalah bahwa tombol aksi yang terhalang bar pemilihan masih dapat diklik
    saat objek tertentu (Tugas, item Toko) dipilih
14. Memperbaiki masalah bahwa mengubah warna Item tidak segera me-refresh UI 15.Memperbaiki
    masalah bahwa tiba-tiba mengatur suku bunga tinggi setelah mempertahankan suku bunga rendah (gagal mendapat 1 emas) mungkin mendapat bunga besar
16. Memperbaiki masalah bahwa kotak pencarian muncul setelah menyelesaikan Tugas setelah membuka bar
    pencarian dan menggunakan produk
18. Memperbaiki masalah bahwa jumlah penyelesaian di App hari itu mungkin tidak cocok dengan widget
    setelah mengubah nama Tugas tak terbatas
19. Memperbaiki animasi aneh saat menyelesaikan Tugas tak terbatas
20. Memperbaiki masalah bahwa menyalin Tugas tidak menyalin latar belakang Tugas
21. Memperbaiki masalah bahwa dalam beberapa kasus, kondisi Pencapaian selesai, tetapi
    Pencapaian tidak dapat dibuka
22. Memperbaiki masalah perhitungan interval tanggal (dapat memengaruhi beberapa logika)
23. Memperbaiki masalah bahwa Perasaan tidak otomatis difilter dari halaman detail Tugas

## Apa selanjutnya?

Kami berencana terus menangani beberapa kebutuhan masukan yang lebih umum di rilis berikutnya.

Misalnya, mode malam disesuaikan dengan warna tema, subtugas memberi Hadiah Poin Pengalaman dan
komoditas, dan pembelian komoditas menambah batas Level Atribut, dll.

Di saat yang sama, kami juga akan menyelidiki kelayakan integrasi Google Calendar di
waktu dekat (tetapi fitur ini mungkin masih membutuhkan 2~3 versi sebelum dirilis).

Karena kami mengembangkan secara independen di waktu luang, di atas hanyalah beberapa tujuan jangka pendek,
dan waktu peluncuran yang sesuai tidak dijamin.

Ikuti kami di Reddit atau Twitter (@AppLifeUp) untuk informasi lebih lanjut.

Jika Anda memiliki pertanyaan atau masukan, ingatlah untuk menghubungi alamat email kami kapan saja untuk
bantuan.

Terima kasih juga kepada semua orang di Reddit yang membangun dan mendiskusikan. Kami juga akan berusaha menerbitkan lebih banyak
artikel bahasa Inggris di masa depan.
