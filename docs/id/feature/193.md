## I. 📋 Template Tugas

![image-20231023213616938](_media/193/image-20231023213616938.png)

Versi ini memperkenalkan template Tugas bawaan. Ini menghilangkan kebutuhan membuat Tugas secara tidak langsung menggunakan "Salin Tugas" dan API.

Saat membuat atau mengedit Tugas, pengguna dapat menyimpan pengaturan saat ini sebagai template.

Di masa depan, saat membuat Tugas, Anda dapat mengimpor pengaturan Hadiah, pengaturan Tugas, dan lainnya dengan satu ketukan.

### 📕 Cara Menggunakan?

Saat membuat atau mengedit Tugas, ketuk tombol Template Tugas di bar atas.

![image-20231023213703434](_media/193/image-20231023213703434.png)

Template Tugas akan merekam sebagian besar pengaturan Anda, tetapi saat ini tidak termasuk tenggat waktu.





## II. 🎨 Tema Material You

![image-20231023213837819](_media/193/image-20231023213837819.png)

![image-20231023213849504](_media/193/image-20231023213849504.png)

Versi ini sepenuhnya beradaptasi ke bahasa desain Material You (tema).

Bahasa desain ini lebih modern dan menawarkan tampilan lebih bersih. Ini juga salah satu gaya UI resmi yang dipromosikan untuk masa depan.

Selain itu, fitur inti Material You adalah "setiap orang dapat memiliki warna tema berbeda."

Ini memungkinkan "LifeUp" memperkenalkan mekanisme baru seperti warna tema dinamis berdasarkan wallpaper dan warna tema kustom. (Catatan: Dukungan perangkat diperlukan.)

### 📕 Cara Menggunakan?

Seperti gambar di atas, buka sidebar, masuk ke Pengaturan, lalu ketuk Tampilan untuk menyesuaikan opsi terkait.

Jika perangkat Anda tidak mendukung warna tema dinamis, Anda masih dapat memilih dari warna tema preset.

Tetapi jika perangkat Anda mendukung warna tema dinamis, Anda dapat mengaktifkan fitur ini dan menyesuaikan warna tema yang diinginkan dengan fleksibilitas tinggi:

![image-20231023213903322](_media/193/image-20231023213903322.png)

## III. ✨ Fitur Lainnya

**Tema UI**

1. Beradaptasi penuh ke Material Design 3.
2. Mendukung kustomisasi warna tema Material Design 3, termasuk warna kustom, warna dari wallpaper, dan warna dari gambar.
3. Meningkatkan beberapa efek animasi, seperti pop-up.
4. Mengoptimalkan efek adaptasi edge-to-edge (immersive).

**Tugas**

1. Mendukung template Tugas.
2. Statistik di halaman detail mendukung beralih berdasarkan kriteria waktu dan mengoptimalkan opsi default.
3. Halaman riwayat mendukung pencarian nama Tugas dan menyesuaikan UI serta interaksi terkait.

**Pencapaian**

![image-20231023214451450](_media/193/image-20231023214451450.png)

1. Mendukung Pencapaian rahasia.
2. Saat menambahkan Pencapaian, mendukung "Lanjutkan Menambah Pencapaian Berikutnya."

**Atribut**

1. Mendukung menyembunyikan Atribut.

**Timer Pomodoro**

1. Mendukung mengedit catatan waktu.
2. Di halaman Pomodoro, mendukung penyelesaian Tugas (tekan lama Tugas terpilih saat mode jeda).

**Perasaan**

1. Mendukung menambahkan Perasaan langsung di halaman Perasaan.

**API**

1. Menambahkan API "use_item".
2. Menambahkan API "random".
3. Menambahkan API "edit_exp".
4. API "item" kini mendukung menyesuaikan parameter seperti "action_text," "disable_use," dan "title_color_string."
5. API "shop_settings" mendukung parameter "silent".
6. Mendukung placeholder "time". Kini Anda dapat mengatur Tugas dengan tanggal seperti "jatuh tempo besok" atau "jatuh tempo bulan depan" tanpa alat otomatisasi.

Selain fitur-fitur ini, kami telah menangani berbagai masalah yang dilaporkan dan melakukan beberapa perbaikan bug. Untuk detail lebih lanjut, lihat log pembaruan berikut.



### ♻️ Optimasi

1. Menambahkan prefix di beberapa tempat yang menampilkan ID data.
2. Mengoptimalkan tampilan aktivitas tim.
3. Mencoba menangani masalah bahwa beberapa notifikasi Toast terlalu panjang untuk ditampilkan penuh.
4. Meningkatkan logika penyelesaian widget di tim, memastikan konsistensi dengan perilaku di App.
5. Halaman statistik: Setelah memilih rentang waktu "Kustom", mengetuk "Kustom" lagi kini memicu pemilihan ulang tanggal.
6. Memastikan kompatibilitas dengan Harmony OS 4 agar notifikasi progress bar menampilkan tombol aksi.
7. Meningkatkan logika interaksi permintaan notifikasi.
8. Menangani masalah bahwa metode input dapat menghalangi input untuk "Jumlah Pengulangan."
9. Kini, saat membuat Tugas, pilihan pengguna untuk waktu mulai non-spesifik (seperti otomatis atau jatuh tempo hari ini) direkam. Saat mengedit, opsi ini dipulihkan, bukan waktu spesifik, untuk menghindari perbedaan waktu yang diedit.
10. Saat membuat Tugas, jika peringatan duplikat tidak terduga muncul, peringatan juga akan ditampilkan di pop-up "Periksa Duplikat."
11. Menambahkan dukungan bahasa Indonesia.
12. Memperbarui terjemahan.

## 🐛 Perbaikan Bug

1. Memperbaiki masalah bahwa, dalam kasus tertentu, modul world bisa macet loading (berputar tanpa henti).
2. Memperbaiki masalah bahwa, dalam kasus tertentu, Toko/gudang bisa terus menampilkan loading (berputar tanpa henti).
3. Memperbaiki masalah yang dapat terjadi saat memanggil API dengan konten UI via content provider.
4. Memperbaiki masalah pengurutan Tugas yang tidak sesuai harapan.
5. Memperbaiki masalah bahwa data di halaman statistik salah setelah memilih rentang waktu "Kustom."
6. Memperbaiki masalah bahwa pop-up permintaan notifikasi tidak mendukung scroll.
7. Memperbaiki masalah bahwa, dalam kasus tertentu, pencarian modul world menampilkan semua konten.
8. Memperbaiki masalah bahwa opsi "Tampilkan Selesai" juga menampilkan Tugas beku.
9. Memperbaiki masalah perhitungan nilai rata-rata di halaman statistik.
