## Pengantar

Pembaruan ini terutama memperkenalkan fitur seperti Hadiah beberapa Item dan widget Inventaris, beserta banyak optimasi, peningkatan performa, dan perbaikan bug.

**📧Cara memberi masukan?**

Jika Anda memiliki pertanyaan, saran, atau laporan bug, hubungi kami di 📫[lifeup@ulives.io](mailto:lifeup@ulives.io) atau kirim issue di GitHub (https://github.com/Ayagikei/LifeUp/issues)



## 1. ✅Hadiah Beberapa Item

![image-20240422223851277](_media/194/image-20240422223851277.png)

Kini, di LifeUp, Anda dapat memilih beberapa Item di berbagai tempat. Anda tidak perlu lagi mengatur membuka kotak atau crafting untuk mencapai beberapa Hadiah.

Misalnya, Anda dapat:

- Langsung mengatur beberapa Hadiah Item untuk Tugas
- Memilih beberapa Item saat mengatur membuka kotak, lalu mengatur probabilitas sekaligus
- Langsung mengatur beberapa Hadiah Item untuk Pencapaian dan subtugas

<br/>

### 📕Cara Menggunakan?

Ketuk tombol multi-pilih di bagian atas saat memilih Item.

> Perhatikan bahwa beberapa skenario mungkin hanya mendukung pemilihan tunggal.

![image-20240422223906505](_media/194/image-20240422223906505.png)

## 2. 🔧Widget Inventaris

![widget_inventory_large_preview](_media/194/widget_inventory_large_preview.png)

Versi ini memperkenalkan dua ukuran widget Inventaris.

Kini, Anda dapat langsung melihat dan menggunakan Item di Inventaris dengan cepat dari desktop.

<br/>

### 🚀 Optimasi dan Penyelesaian Masalah

Meskipun widget Toko diluncurkan beberapa versi lalu, kami perlahan menghadapi beberapa crash atau masalah lain.

Misalnya, karena batas transmisi sistem widget, terlalu banyak Item mungkin menyebabkan App crash, atau masalah beralih daftar, atau kegagalan loading gambar kustom.

Di versi ini, kami menemukan solusi yang tepat. Kini, widget Toko dan Inventaris seharusnya dapat menampilkan banyak Item, dan kami telah menguji widget Toko dengan hampir 1000 Item yang masih berfungsi dan dimuat dengan baik (tentu saja, ini tidak disarankan).

<br/>

### 📕Cara Menggunakan?

Biasanya, Anda dapat membuat widget dengan menekan lama desktop sistem.

Jika Anda menggunakan perangkat seperti Xiaomi atau Redmi (MIUI/HyperOS), menambahkan widget di MIUI/HyperOS agak tersembunyi; silakan lihat dokumen konfigurasi kompatibilitas tentang cara menambahkan widget.

## 3. ✨Fitur Lainnya

**Tema UI**

![image-20240422223925926](_media/194/image-20240422223925926.png)

1. Warna kustom (teks Tugas, Item) kini mencakup lebih banyak nilai preset
2. Beradaptasi ke fitur ikon adaptif monokrom Android 14
3. Menambahkan lebih banyak adaptasi bahasa (versi Google Play)

**Pencapaian**

![image-20240422223959899](_media/194/image-20240422223959899.png)

1. Jika ada Pencapaian dengan Hadiah belum diklaim, titik merah kecil kini ditampilkan di daftar Pencapaian.

**Tugas**

![image-20240422224026331](_media/194/image-20240422224026331.png)

1. Subtugas untuk Tugas penalti kini akan menjalankan logika penalti dengan benar
2. Menambahkan "Manajemen Zona Waktu Pintar"; jika Anda terlibat pekerjaan lintas zona waktu, LifeUp juga mendukung deteksi otomatis perubahan zona waktu dan penyesuaian waktu global
3. Dasar statistik di halaman detail kini mengingat pilihan terakhir, dan kami mengoptimalkan beberapa nilai default dalam skenario tertentu
4. Mengoptimalkan penanganan grace hari penyelesaian Tugas berkelanjutan di halaman "Saya"; kini jika Anda lupa menyelesaikan Tugas satu hari, mengejar tetap dapat melanjutkan streak

**Atribut**

![image-20240422224041201](_media/194/image-20240422224041201.png)

1. Mendukung menghapus catatan Poin Pengalaman
2. Mendukung mereset Poin Pengalaman Atribut individual

**Widget**

1. Kini, mengetuk ruang kosong di widget Toko atau Inventaris langsung masuk ke daftar yang dituju widget, bukan daftar terakhir
2. Widget Tugas kini menampilkan progres Tugas count

**API**

1. Menambahkan API untuk mengedit catatan Pomodoro
2. API menyelesaikan Tugas kini juga menangani Tugas penalti dengan benar
3. API menyelesaikan Tugas kini juga mendukung memproses Tugas count (menambahkan parameter `count`)
4. API menyelesaikan Tugas kini mendukung parameter koefisien Hadiah
5. API menyesuaikan Item kini mendukung mengubah id daftar Item
6. API membuat dan menyesuaikan Item mendukung parameter kriteria pengurutan
7. API Jump kini mendukung melompat ke popup gunakan Item
8. Menyatukan beberapa definisi parameter, seperti `itemId` → `item_id`
9. Menambahkan broadcast notifikasi untuk memulai, menjeda, dan mengakhiri stopwatch
10. API menyesuaikan Item `title_color_string` kini mendukung meneruskan string kosong untuk memulihkan nilai default
11. Broadcast menyelesaikan Tugas kini menyertakan id daftar
12. Membuka kotak, crafting kini juga memicu broadcast gunakan Item

Selain ini, kami telah memperbaiki banyak masalah dan beberapa bug yang dilaporkan belakangan.

Detail dapat ditemukan di log pembaruan di bawah~

### ♻️Optimasi

1. Menambah atau mengedit Tugas kini menyertakan peringatan jika tidak ada Atribut dipilih dan Poin Pengalaman dimasukkan
2. Mengoptimalkan catatan retry unggah
3. Mengoptimalkan tampilan judul dan batasan input di halaman Level kustom
4. Mengoptimalkan performa dan masalah timing undo Tugas yang telah diulang secara ekstensif
5. Merefaktor popup gunakan Item, logika antarmuka kalender, dll.
6. Mengoptimalkan logika terkait pengingat Tugas, memastikan pengingat dari data yang dihapus atau sebelumnya tidak dikirim lagi
7. Mengoptimalkan teks menunggu di antarmuka cadangan
8. Gambar yang dipilih di halaman Atribut kustom juga ditambahkan ke pilihan riwayat
9. Mengedit catatan Pomodoro kini mencoba mengoreksi (menambah atau mengurangi) jumlah Pomodoro yang tepat

### 🐛Perbaikan Bug

1. Memperbaiki Pencapaian sistem terkait statistik dan cadangan yang tidak terpicu normal setelah restrukturisasi
2. Memperbaiki potensi konflik antara widget API random dan toast dengan toast default
3. Memperbaiki detail Tugas tidak refresh dalam beberapa skenario saat masuk dari widget
4. Memperbaiki potensi error dalam beberapa kali membuka kotak dalam situasi khusus (menggunakan Inventaris Item lebih dulu)
5. Memperbaiki masalah tidak menampilkan subtugas di halaman detail setelah mengedit Tugas tanpa subtugas dan menambahkan yang baru
6. Memperbaiki beberapa kasus khusus di mana mengedit Hadiah koin tidak memungkinkan
7. Memperbaiki beberapa kasus di mana mengklaim Item tim mungkin tidak berfungsi
8. Memperbaiki anomali gaya MD2 di beberapa popup bawah
9. Memperbaiki potensi nilai waktu tambahan salah di timer Pomodoro
10. Memperbaiki masalah bar warna di widget perubahan Poin Pengalaman mungkin tidak ditampilkan
11. Memperbaiki beberapa Tugas tidak ditampilkan dengan benar di kalender-in-progress
12. Memperbaiki beberapa masalah loading daftar di halaman riwayat, Perasaan
13. Memperbaiki masalah memanggil API selesaikan Tugas dua kali berturut-turut dengan cepat tidak memungkinkan dua penyelesaian berurutan
