# 2022/10 - 2023/12 開発計画

!> これは期限切れの開発計画であり、アーカイブと参照目的でのみ保持しています。環境は変化し続けており、計画もそれに応じて調整されます。この計画は開発の方向性を大まかに示しますが、完全に実行することを約束するものではなく、計画を超えた開発も行う場合があります。

<br/>

LifeUp のこれまでの開発は、新しい機能モジュールの開発、または既存モジュールへの新機能追加に重点を置いてきました。

現在、LifeUp の機能モジュールは自己完結的な幅は十分にある一方、深さが不足していると考えています。

したがって、以下の開発目標は機能の深さを目指し、既存の利用可能なモジュールを継続的に改善し、実用性（カレンダー連携、ウィジェット、統計）を高めます。

また、API 機能を継続的に拡張し、API がさまざまな外部機能に十分拡張できるようにします。
加えて、データシステムの改善を試み、Flutter を用いたクロスプラットフォーム版の開発を検討します。

<br/>

- **2023/01/26**
  - 「マルチプラットフォーム」に「LAN PC 側」項目を追加、「APIs」にも対応する説明を追加。
