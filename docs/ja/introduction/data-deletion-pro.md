# *LifeUp Pro* のデータ削除リクエスト

## 1. LifeUp Pro でのデータ削除

LifeUp Pro ユーザーは App 内で独立してデータを削除できます。

LifeUp Pro は主にオフラインアプリケーションのため、端末上で直接データを管理できます。

データを削除する手順：

1. LifeUp Pro App の「設定 → データバックアップ/復元/消去」ページに移動。
2. タスク、アイテム報酬、ローカルの考え、オフラインモードデータなど、削除したい特定のデータを選択。
3. 操作を確認し、選択したデータを永久に削除。

**または、端末から LifeUp Pro App をアンインストールすると、ローカルに保存されたすべてのデータも削除されます。**



## 2. LifeUp Pro でのアカウント削除

LifeUp Pro でのアカウント削除は、データ削除とは別のプロセスです。

アカウントを削除すると、以下が削除されます：

- サーバーに公開したチームや更新などの公開投稿。
- アカウントに関連するニックネームやその他の個人情報。
- アカウントにリンクされた OAuth 関連付け。

**LifeUp Pro アカウントを削除する手順：**

1. 「設定 → データバックアップ/復元/消去」ページに移動。
2. ページ下部の「アカウント削除」ボタンをタップ。
3. 操作を確認し、アカウントと関連するすべての情報を永久に削除。

<br/>

**LifeUp Pro App を使用していないが、アカウントと個人データを削除したい場合は、[lifeup@ulives.io](mailto:lifeup@ulives.io) までお問い合わせください。**

アカウントに関連する必要な詳細を提供していただければ、削除プロセスをサポートします。

プライバシーを確保するため、リクエストは最大限の注意と機密性をもって対応します。



## 3. サードパーティサービス

LifeUp Lite と同様、LifeUp Pro は機能強化のために Firebase などのサードパーティサービスと統合しています。これらのサービスが収集するデータは個人を特定できず、プライバシーポリシーに従って管理されます。このデータは、サードパーティサービスのポリシーに従い、一定期間後に自動削除がスケジュールされます。



## 4. 更新とコンプライアンス

最新のプライバシー法と業界標準に合わせるため、継続的に慣行を監視・更新しています。プライバシーポリシーのこのセクションは、LifeUp Pro ユーザーのデータ管理と削除プロセスを正確に反映するため、必要に応じて改訂されます。
