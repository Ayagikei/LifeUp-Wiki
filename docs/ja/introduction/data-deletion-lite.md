# *LifeUp Lite* のデータ削除リクエスト

## 1. データ保存と削除

LifeUp Lite（LifeUp の無料版）は、主にユーザーの端末にデータを保存します。プライバシーと自律性を大切にしています。

LifeUp Lite ではユーザーアカウントが作成されないため、すべての個人データは端末にローカル保存されます。

**このデータを削除するには、端末から LifeUp Lite アプリケーションをアンインストールするだけです。アンインストール時、ローカルに保存されたすべてのデータが永久に削除されます。**

## 2. サードパーティサービス

LifeUp Lite は、機能と広告のために Firebase や Admob などのサードパーティサービスと統合しています。

これらのサービスが収集するデータには、身元に紐付けられた個人情報は含まれず、それぞれのプライバシーポリシーに準拠して使用されます。

このデータは、これらのサービスのポリシーに従い、一定期間後に自動削除されます。

## 3. データ削除のサポート

データ削除に関するサポートやご質問がある場合は、lifeup@ulives.io までお気軽にお問い合わせください。

データプライバシーに関するご質問やご懸念にお答えし、必要に応じてプロセスをご案内します。

## 4. コンプライアンスと更新

最新の規制と業界標準への準拠を確保するため、継続的に慣行を見直し更新しています。プライバシーポリシーのこのセクションは、データ管理と削除プロセスの変更を反映するため、必要に応じて更新されます。
