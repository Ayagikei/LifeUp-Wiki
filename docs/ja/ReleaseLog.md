2. **カスタムタスク並び順メカニズムを改善**：コピー、完了、元に戻す、その他のエッジケースでもカスタム順序が安定する新しい並び順メカニズムを導入。

**♻️ 最適化**

1. **Android 予測的戻るジェスチャーに対応**：タスク、ショップ、合成、実績エディターがシステムの予測的戻るジェスチャーに対応。
2. **Facebook ログイン初期化を改善**：ログイン要求時に SDK を初期化し、エラー状態の処理を改善。

**🐛 バグ修正**

1. **編集 URL Scheme リクエストが既存フィールドを意図せず上書きする問題を修正**：省略されたフィールドは以前の値を保持し、無効な報酬または関連パラメーターが既存データを消去しなくなりました。
2. **特定のエッジケースで正タイマー通知タイトルが選択タスクに追従しない問題を修正。**
3. **16 進カラー値を最初に貼り付けた後、RGB プレビューが更新されない問題を修正。**
4. **合成および実績詳細ページの選択ツールバーに影が欠ける問題を修正。**

**v1.104.0 (2026/05/23)**

**✨ 新機能**

**♻️ 最適化**

1. **ショップアイテム表示フィルターをより精密に**：売り切れアイテムに加え、購入不可、購入制限、現在購入不可のアイテムを非表示に可能。ショップウィジェットも同じルールに従います。

5. **ショップ設定の入力動作を改善**：ショップ設定でフォーカス中の入力がソフトキーボードの上にスクロール。
6. **システムダークモード処理をより信頼性向上**：システムテーマ追従と手動ナイトモード切り替え間の状態競合を修正。
