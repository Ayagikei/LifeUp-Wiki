# サポート

サポートはいつもありがたいものです。❤️

皆さんのサポートにより、開発により多くの時間を割き、より良いサーバーや新機能など、より多くのリソースを確保できます。

まだ実現したいアイデアもたくさんあります。

## すべての方へ

### アプリをシェア

[当 App](https://play.google.com/store/apps/details?id=net.sarasarasa.lifeup) を友人にシェア・おすすめするのも大きな助けになります。

### 評価・ご提案

Google Play での評価をご検討ください。❤️

ご提案もいつでも歓迎します。


### Buy me a coffee

App が本当に役立っているなら、App の **About** ページでコーヒーを一杯おごっていただくことでサポートをご検討ください。

また、LifeUp を友人やコミュニティに紹介していただくのも、素晴らしいサポート方法です！


## 翻訳者

App の翻訳を手伝っていただくのも大きな助けになります。現在 AI 支援翻訳を導入していますが、人間によるレビューは依然として不可欠です。

翻訳プロジェクトは Crowdin でホストされています：[LifeUp on Crowdin](https://crowdin.com/project/lifeup)。

特定の翻訳問題を見つけた場合や、新しい言語への貢献を希望される場合は、Crowdin プロジェクトへの参加、または直接お問い合わせください。


## API & 連携

LifeUp は幅広い API と連携オプションを提供しています。これらの API に基づくコミュニティ主導の創作と共有を大歓迎します！

カスタムスクリプト、デスクトップ連携、LifeUp との新しいやり取りの方法——皆さんの貢献が LifeUp エコシステムの拡大に役立ちます。

詳細は [API ドキュメント](guide/api.md) をご覧ください。
