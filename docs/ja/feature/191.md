## ✨マルチプラットフォーム：デスクトップ

![](_media/191/04.png)

![](_media/191/05.png)

この期間、新しい試みとして、新 API 更新により各種詳細リストデータのクエリが可能になりました。

**完全オープンソース（https://github.com/Ayagikei/LifeUp-Desktop）** の LAN デスクトップソフトウェアを開発し、端末に接続して各種リストデータを表示し、商品購入、タスク完了、振り返り画像のエクスポートとシステム画像ブラウザでの閲覧など、いくつかのシンプルな操作に対応しています。

理論上、Windows、Linux、macOS に対応しています。



⚠️ デスクトップはまだ初期開発段階であることにご注意ください。

引き続きメンテナンスし、デスクトップからのタスク追加、操作向けインターフェース適応、振り返りの Markdown 形式エクスポートなど、機能を追加していきます。

### 📝使い方

詳細は「サイドバー → 設定 → ラボ → LifeUp Cloud」をご覧ください。

ドキュメントもご確認ください：[LifeUp Desktop🖥 (lifeupapp.fun)](https://docs.lifeupapp.fun/en/#/guide/api_desktop)。





## ✏️API：フルリストデータのクエリとその他 API

![](_media/191/06.png)

**データインターフェース**

デスクトップクライアントのデータソース基盤として、このバージョンで完全なデータクエリインターフェースを提供します。

Android 開発者の方は、**LifeUp SDK** で LifeUp App 内の各種データをクエリできます。

その他の開発者の方は、HTTP プロトコルで「LifeUp Cloud」API を呼び出せます。デスクトップクライアントでも同様の方法を採用しています。

開発について詳しくない方も、ご心配なく：

1. まず、今が最高の学習機会です。

2. 次に、上記のデータ API は公開されているため、コミュニティ開発者がこのデータで二次開発できます。

例えば、タスクリストページ、ショップページの設計や、より複雑な二次開発（割引、カブ売買機能など）が可能です。

二次開発の成果もすべてのユーザーに恩恵をもたらします。



具体的なインターフェースは後日 API ドキュメントに追加されます。

**その他 API インターフェースの改善**

追加

- ATM 入出金
- アイテムの「購入禁止」設定
- タスクの「タグ色」設定
- ATM 残高の直接設定
- 指定アイテム詳細のシンプルクエリ
- 「confirm_dialog」インターフェースに第 3 ボタンと操作オプションを追加

動作変更

- confirm_dialog ポップアップ API で、一部ボタンのテキストや操作が未指定の場合、そのボタンは表示されません。

  ポップアップ制御の柔軟性が高まり、例えばテキストのみでボタンなしのポップアップを設定し、テキストやモチベーション文言を表示できます。

- ペナルティ API では、以前のバージョンでは最大 100 アイテムまで差し引けましたが、現在は 9 桁まで拡張されました。

### 📝 使い方

API ドキュメントと GitHub リポジトリをご確認ください。

[LifeUp Cloud☁️ (lifeupapp.fun)](https://docs.lifeupapp.fun/en/#/guide/api_cloud)

https://github.com/Ayagikei/LifeUp-SDK

## 🍅ポモドーロ：作業・休憩タイミングの自動開始

![screely-1676558398757](_media/191/07.png)

このバージョンでは、ポモドーロクロックの自動開始機能も導入します。

端末が **互換性設定** 済みであることを確認し、システムがポモドーロクロックの動作を中断しないようにしてください。

「休憩の自動開始」をオンにすると、従来の追加カウントダウン機能は無効になります。

### 📝 使い方

ポモドーロ → 右上の設定ページへ。

## 🚀その他：パフォーマンス最適化

ユーザーフィードバックとオンラインデータ収集により、LifeUp App 内の一部データクエリは、データ量が多い場合に効率が大幅に低下することが分かりました。

To-Do リストツール App にとって、安定性と長期利用は極めて重要です。

そのため、このバージョンでは大量データシナリオ向けに一連の最適化を行いました。ほとんどのリストページ（特に To-Do リストページ）の読み込み速度を大幅に改善できます。

これらのシナリオ向けの最適化を続けます。
