## 1. ✅複数アイテム報酬

![image-20240422223851277](_media/194/image-20240422223851277.png)

LifeUp では、さまざまな場所で複数のアイテムを選択できるようになりました。箱を開ける設定や合成を使わなくても、複数の報酬を設定できます。

例えば次のことができます。

- タスクに複数のアイテム報酬を直接設定
- 箱を開ける設定で複数アイテムを選び、確率を一括設定
- 実績やサブタスクに複数のアイテム報酬を直接設定

<br/>

### 📕使い方

アイテム選択時、上部の複数選択ボタンをタップしてください。

> 一部のシナリオでは単一選択のみ対応している場合があります。

## 2. 🔧インベントリウィジェット

![widget_inventory_large_preview](_media/194/widget_inventory_large_preview.png)

このバージョンでは、2 サイズのインベントリウィジェットを追加しました。

デスクトップからインベントリ内のアイテムを直接確認し、素早く使用できます。

<br/>

### 🚀 最適化と問題解決

ショップウィジェットを数バージョン前に公開して以来、クラッシュなどの問題が徐々に見られるようになりました。

例えば、ウィジェットシステムの転送制限により、アイテムが多すぎると App がクラッシュしたり、リスト切り替えの問題、カスタム画像の読み込み失敗などが起きることがありました。

このバージョンでは適切な解決策を見つけました。ショップとインベントリのウィジェットは大量のアイテムを表示できるようになり、ショップウィジェットは約 1000 アイテムでも動作・読み込みできることを確認しました（もちろん、推奨はしません）。

<br/>

### 📕使い方

通常、システムのデスクトップを長押ししてウィジェットを作成できます。

Xiaomi や Redmi（MIUI/HyperOS）などの端末をお使いの場合、MIUI/HyperOS ではウィジェット追加がやや分かりにくい場所にあります。互換性設定ドキュメントでウィジェットの追加方法をご確認ください。

## 3. ✨その他の機能

**UI テーマ**

![image-20240422223925926](_media/194/image-20240422223925926.png)

1. カスタム（タスク、アイテムテキスト）色にプリセット値を追加
2. Android 14 のモノクローム適応アイコン機能に対応
3. 言語対応を追加（Google Play 版）

**実績**

![image-20240422223959899](_media/194/image-20240422223959899.png)

1. 未受け取り報酬がある実績がある場合、実績リストに小さな赤い点を表示

**タスク**

![image-20240422224026331](_media/194/image-20240422224026331.png)

1. ペナルティタスクのサブタスクがペナルティロジックを正しく実行
2. 「スマートタイムゾーン管理」を追加。タイムゾーンを跨ぐ作業がある場合、LifeUp はタイムゾーン変更の自動検出とグローバルな時間調整に対応
3. 詳細ページの統計基準が最後の選択を記憶。一部シナリオのデフォルト値も最適化
4. 「マイ」ページの連続タスク完了日数の猶予処理を最適化。1 日忘れても、後から完了すれば連続記録を継続可能

**属性**

![image-20240422224041201](_media/194/image-20240422224041201.png)

1. 経験値記録の削除に対応
2. 個別属性の経験値リセットに対応

**ウィジェット**

1. ショップまたはインベントリウィジェットの空白部分をタップすると、最後のリストではなくウィジェットが指すリストに直接入る
2. タスクウィジェットでカウントタスクの進捗を表示

**API**

1. ポモドーロ記録を編集する API を追加
2. タスク完了 API がペナルティタスクも正しく処理
3. タスク完了 API がカウントタスクの処理にも対応（`count` パラメータを追加）
4. タスク完了 API が報酬係数パラメータに対応
5. アイテム調整 API がアイテムリスト id の変更に対応
6. アイテム作成・調整 API がソート基準パラメータに対応
7. ジャンプ API がアイテム使用ポップアップへのジャンプに対応
8. 一部パラメータ定義を統一（例：`itemId` → `item_id`）
9. ストップウォッチの開始、一時停止、終了のブロードキャスト通知を追加
10. アイテム調整 API の `title_color_string` が空文字列を渡してデフォルト値に戻すことに対応
11. タスク完了ブロードキャストにリスト id を含める
12. 箱を開ける、合成でもアイテム使用ブロードキャストをトリガー

------

これに加え、最近報告された多数の問題修正とバグ修正を行いました。

詳細は以下の更新ログをご覧ください。

### ♻️最適化

1. タスクの追加・編集時、属性が未選択で経験値が入力されている場合に警告を表示
2. アップロード再試行記録を最適化
3. カスタムレベルページのタイトル表示と入力制限を最適化
4. 大量に繰り返されたタスクの取り消しのパフォーマンスとタイミング問題を最適化
5. アイテム使用ポップアップ、カレンダーインターフェースロジックなどをリファクタリング
6. タスクリマインダー関連ロジックを最適化。削除済みまたは以前のデータからのリマインダーが再発行されないことを保証
7. バックアップインターフェースの待機文言を最適化
8. カスタム属性ページで選択した画像も履歴選択に追加
9. ポモドーロ記録の編集時、正しいポモドーロ数の補正（増減）を試行

### 🐛バグ修正

1. 再構築後に統計・バックアップ関連のシステム実績が正常にトリガーされない問題を修正
2. ランダム API と toast API ウィジェットがデフォルト toast と競合する可能性を修正
3. ウィジェットから入った際、一部シナリオでタスク詳細が更新されない問題を修正
4. 一部特殊状況での複数回の箱開けエラー（アイテムインベントリの先取り使用）の可能性を修正
5. サブタスクなしでタスクを編集し新規追加した後、詳細ページにサブタスクが表示されない問題を修正
6. コイン報酬の編集ができない特殊ケースを修正
7. チームアイテムの受け取りが動作しない場合を修正
8. 一部ボトムポップアップの MD2 スタイル異常を修正
9. ポモドーロタイマーで追加時間値が誤る可能性を修正
10. 経験値変化ウィジェットでカラーバーが表示されない場合がある問題を修正
11. カレンダー進行中に一部タスクが正しく表示されない問題を修正
12. 履歴、気分ページの一部リスト読み込み問題を修正
13. タスク完了 API を短時間に 2 回連続呼び出しても 2 回連続完了できない問題を修正
