## I. 📋 タスクテンプレート

![image-20231023213616938](_media/193/image-20231023213616938.png)

このバージョンでは、組み込みのタスクテンプレートを導入しました。「タスクをコピー」や API を使った間接的な作成が不要になります。

タスクの作成・編集時に、現在の設定をテンプレートとして保存できます。

今後タスクを作成する際、以前の報酬設定、タスク設定などをワンタップで取り込めます。

### 📕 使い方

タスクの作成・編集時、上部バーの「タスクテンプレート」ボタンをタップしてください。

![image-20231023213703434](_media/193/image-20231023213703434.png)

タスクテンプレートは設定の大部分を記録しますが、現時点では期限は含まれません。





## II. 🎨 Material You テーマ

![image-20231023213837819](_media/193/image-20231023213837819.png)

![image-20231023213849504](_media/193/image-20231023213849504.png)

このバージョンでは Material You デザイン言語（テーマ）に完全対応しました。

このデザイン言語はよりモダンで、すっきりした見た目です。将来公式に推奨される UI スタイルのひとつでもあります。

Material You の核心は「誰もが異なるテーマカラーを持てる」ことです。

これにより、LifeUp は壁紙に基づく動的テーマカラーやカスタムテーマカラーなどの新しい仕組みを導入できます。（注：端末の対応が必要です。）

### 📕 使い方

上記の画像のとおり、サイドバーを開き、設定 → 表示 で関連オプションを調整してください。

端末が動的テーマカラーに非対応の場合でも、プリセットのテーマカラーから選べます。

動的テーマカラーに対応している端末では、この機能を有効にし、柔軟に好みのテーマカラーをカスタマイズできます。

## III. ✨ その他の機能

**UI テーマ**

1. Material Design 3 に完全対応。
2. Material Design 3 テーマカラーのカスタマイズに対応（カスタム色、壁紙からの色、画像からの色）。
3. 一部アニメーション効果を改善（例：ポップアップ）。
4. エッジツーエッジ（没入型）適応効果を最適化。

**タスク**

1. タスクテンプレートに対応。
2. 詳細ページの統計が時間基準での切り替えに対応。デフォルトオプションも最適化。
3. 履歴ページでタスク名の検索に対応。関連 UI と操作も調整。

**実績**

![image-20231023214451450](_media/193/image-20231023214451450.png)

1. シークレット実績に対応。
2. 実績追加時、「次の実績を続けて追加」に対応。

**属性**

1. 属性の非表示に対応。

**ポモドーロタイマー**

1. 時間記録の編集に対応。
2. ポモドーロページでタスク完了に対応（一時停止モード中、選択中のタスクを長押し）。

**気分**

1. 気分ページから直接気分を追加可能に。

**API**

1. 「use_item」API を追加。
2. 「random」API を追加。
3. 「edit_exp」API を追加。
4. 「item」API で「action_text」「disable_use」「title_color_string」などのパラメータ調整に対応。
5. 「shop_settings」API が「silent」パラメータに対応。
6. 「time」プレースホルダーに対応。「明日が期限」「来月が期限」などの日付付きタスクを、自動化ツールなしで設定可能に。

これらに加え、報告されたさまざまな問題への対応とバグ修正を行いました。詳細は以下の更新ログをご覧ください。



### ♻️ 最適化

1. データ ID を表示する一部箇所にプレフィックスを追加。
2. チーム活動の表示を最適化。
3. 一部 Toast 通知が長すぎて全文表示されない問題への対応を試行。
4. チームでのウィジェット完了ロジックを改善。App 内の動作と一貫性を確保。
5. 統計ページ：「カスタム」時間範囲選択後、再度「カスタム」をタップすると日付の再選択がトリガーされる。
6. Harmony OS 4 でプログレスバー通知のアクションボタン表示の互換性を確保。
7. 通知リクエストの操作ロジックを強化。
8. 「繰り返し回数」入力時に入力メソッドが入力を妨げる問題に対応。
9. タスク作成時、特定開始時刻以外（自動や今日が期限など）の選択を記録。編集時は具体的な時刻ではなくこれらのオプションを復元し、編集後の時刻のずれを回避。
10. タスク作成時、重複に関する予期しない警告が発生した場合、「重複を確認」ポップアップにも表示。
11. インドネシア語に対応。
12. 翻訳を更新。

## 🐛 バグ修正

1. 特定の場合に World モジュールが読み込みのまま止まる（無限に回転）問題を修正。
2. 特定の場合にショップ／倉庫が読み込み表示のままになる問題を修正。
3. Content Provider 経由で UI コンテンツ付き API を呼び出した際の問題を修正。
4. 期待どおりでないタスクソートの問題を修正。
5. 「カスタム」時間範隔選択後に統計ページのデータが誤る問題を修正。
6. 通知リクエストのポップアップがスクロール非対応だった問題を修正。
7. 特定の場合に World モジュール検索がすべてのコンテンツを表示する問題を修正。
8. 「完了を表示」オプションが凍結タスクも表示する問題を修正。
9. 統計ページの平均値計算の問題を修正。
