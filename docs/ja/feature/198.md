<h1 align="center" padding="100">v1.98.0 API 2.0 とデスクトップクライアントの更新</h1>


## はじめに
2025 年最初のリリースです。主な更新内容は次のとおりです。

- Emoji アイコン対応：アイテム、実績などのアイコンに Emoji を直接使えるようになりました。

- API 第 2 波の更新：API インターフェースでタスクの編集、アイテム効果の編集、実績の解除条件、合成、ほぼすべてのコア機能の変更に対応しました。

- LifeUp Cloud とデスクトップクライアントの最適化：自動接続検出の体験を改善。デスクトップクライアントに「新しい気分」機能を追加し、バックアップデータのインポート／エクスポートに対応しました。

## I. Emoji アイコン

### 📕使い方

- このバージョンでは、アイテムや実績などのアイコンを選ぶ際、Emoji 表情を直接アイコンとして選べます。

## II. API 第 2 波の更新
![image-20250106212817689](./_media/198/image-20250106212817689.png)

v1.90.0 で API 機能を公開して以来、多くのユーザーが API を積極的に試し、豊富なコンテンツを作ってくれています。URL 関連の知識をゼロから学び、デスクトップウィジェットや DIY デスクトップクライアントの作成、Web アプリケーション連携まで成功した方もいて、とても印象的です。

ただし、データ構造が複雑で設計・開発の工数も大きかったため、第 1 批の API にはタスクの編集、アイテムの編集、解除条件付き実績の作成、使用効果付きアイテムの作成など、コア機能の一部が不足していました。これらの完成は今回のバージョンまで続きました。

クラウド、デスクトップクライアント、API ドキュメントの設計・開発・テスト・更新により、工数は指数関数的に増え、数か月前に始めた開発ブランチも、ようやく開発とテストが完了した段階です。

**しかし、努力は実を結びました！ 今日、API は LifeUp のほぼすべてのコア機能をカバーしています。API を公開することで、LifeUp を単なる App ではなく、ユーザーが自由に開発・拡張・カスタマイズできるオープンプラットフォームにしたいと考えています。**

### 📕使い方

- API の使い方は、ドキュメントライブラリ → ディレクトリ → オープンインターフェースを参照してください。
- 新しい API インターフェースの定義をドキュメントに追加しました。

## III. デスクトップクライアント：アーカイブ機能と気分

### アーカイブ

![image-20250106212442295](./_media/198/image-20250106212442295.png)

デスクトップクライアントでバックアップファイルを直接エクスポート／インポートできるようになりました。

他の端末へのデータ移行や復旧がより簡単になります。

### 新しい気分の公開

![image-20240927225309975](./_media/198/image-20240927225309975.png)

デスクトップクライアントから新しい気分を公開できるようになりました。画像の追加や時間設定にも完全対応しています。

⚠️注意：気分の編集にはまだ対応していません。

### その他の更新

- 接続関連のエラーメッセージと説明を最適化：ネットワークの問題か、LifeUp バックエンドが動いていないかを明確に表示
- タスク詳細の表示に対応
- API Token のセキュリティ検証に対応（任意、LifeUp Cloud 2.0.0 が必要）
- 購入ロジックを、以前の「アイテム数量調整 API」＋「コイン数量調整 API」から新しい「アイテム購入 API」に変更。購入上限ロジックを正しく処理でき、App との一貫性を保てます。

今回の更新は、デスクトップクライアントのすべての機能が API 経由で実装されていることから、API の能力を示すものでもあります。

## IV. LifeUp Cloud の最適化

> LifeUp Cloud は API を HTTP インターフェースとして公開し、デスクトップクライアント接続の架け橋となるツールです。

![image-20250106212715220](./_media/198/image-20250106212715220.png)

![image-20250106212725277](./_media/198/image-20250106212725277.png)

LifeUp Cloud に関するフィードバックをもとに、多数の最適化を行いました。

- ステータス表示を追加し、デスクトップクライアントが接続できない理由を素早く確認可能に
- 詳細設定を追加
  - クロスオリジンアクセスを許可：Web ベースの技術で LifeUp Cloud の HTTP インターフェースにアクセスする際に有用
  - カスタムサービスポートを許可
  - アクセストークンの設定を許可：任意のセキュリティ検証手段
- LifeUp Cloud インターフェースのエラー戻り値と仕様を最適化
- サービス検出と HTTP サービス切り替えロジックを最適化。デスクトップクライアントの自動検出がより良く動作するはずです

## V. プレビュー

今回の更新は API 以外の機能が比較的少ないため、開発中を含む今後のバージョン内容をプレビューします。

- **大型機能：** 繰り返し可能な実績
- **中型機能：** カスタム背景のテキスト可読性の最適化
  - 小さな変更だと思っていたが、かなり複雑だった
- **小型機能：** 通知に完了と後でリマインドアクションを追加
  - 永続通知の対応を当初計画していたが、新しい Android バージョンでは真の永続表示がサポートされなくなったため見送り
