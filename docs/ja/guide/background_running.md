# LifeUp をバックグラウンドで実行し続ける

## なぜ必要か

一部の端末メーカーは、バッテリー性能のベンチマーク向上のため、バックグラウンド App を積極的に制限します。その結果、バックグラウンド実行に依存する機能が動作しない場合があります。

### 互換性への影響一覧

| 機能 | バックグラウンド常駐が必要？ | 追加の権限 | 備考 |
| --- | --- | --- | --- |
| タスクリマインダー（システム通知） | ✔️ | 通知権限 | これがデフォルトのリマインダー方式です。リマインダーが遅延または届かない場合は、バックグラウンド常駐を設定し、LifeUp の通知が有効になっていることを確認してください。 |
| タスクリマインダー（カレンダーイベント） | ✖️ | カレンダーの読み書き権限 | `設定` → `タスク` → `リマインダーシステムの変更` でこのモードに切り替えられます。 |
| ポモドーロ終了リマインダー | ✔️ | - | 常駐設定がない場合、リマインダーを見逃したり、バックグラウンドでカウントダウンが一時停止・停止したりする可能性があります。 |
| カウントアップタイマー | ✖️ | - | - |
| App ウィジェットの自動更新 | 通常は必要（端末／OS 依存） | - | 適切な常駐設定がない場合、ウィジェットが「読み込み中」のままになったり、「すべてのタスク完了」など古い状態のままになることがあります。 |
| ウィジェット操作：回数タスク完了 / タスク詳細を開く（非 MIUI） | ✖️ | - | - |
| ウィジェット操作：回数タスク完了 / タスク詳細を開く（MIUI） | 場合による | MIUI 固有のバックグラウンドポップアップ／表示権限が必要な場合あり | MIUI では、バックグラウンドからのウィジェット操作による UI アクションがブロックされることがあります。 |

- 一部のシステムでは、画面オフ時にバックグラウンドタスクを凍結または終了します。
- ウィジェットの挙動は、ランチャーや OS バリアントによって異なる場合があります。
- リマインダーだけが必要な場合は、カレンダーリマインダーに切り替えて、バックグラウンド依存を減らすことができます。

## 設定方法

> [!WARNING]
> これらの設定により、バッテリー消費がわずかに増える場合があります。

OnePlus 8T でのテストでは、24 時間のバックグラウンド使用で約 **30 mAh** を消費しました。多くのユーザーにとって、影響は小さいです。

LifeUp がバックグラウンドで行うのは、リマインダー、ウィジェット更新、ポモドーロ計時など、限定的な受動的な操作のみです。

---

### 一般的な設定手順

#### 一般設定

> すべての手順を完了する必要はありません。各ステップはバックグラウンド優先度と安定性を向上させます。

**Android システム設定**

1. LifeUp で `サイドバー` → `設定` → `互換性の問題` を開き、`バッテリー最適化設定へ移動` をタップ。LifeUp を見つけ、**最適化しない** に設定。

   a. 端末によっては、このページに移動しても LifeUp が表示されない場合があります。その場合はこのステップをスキップしてください。

2. リマインダーが必要な場合は、LifeUp に通知権限が付与されていることを確認。

3. （任意）タスク設定で `クイック追加通知` を有効化。

<br/>

**メーカーのバックグラウンド管理（Phone Manager）**

多くのメーカーは追加のバックグラウンド制限を設けています。Pixel / AOSP 系端末でない場合、通常は追加設定が必要です。

1. システムのマルチタスク／最近使った App 画面で LifeUp をロック。

2. システムの App 管理 / バッテリー管理 / Phone Manager で、LifeUp にバックグラウンド実行を許可（制限なし）および自動起動を許可。

   a. メーカー固有のガイドは [dontkillmyapp.com](https://dontkillmyapp.com/) を参照。

3. LifeUp の機能を使用する際、超省電力モードや厳格なおやすみモードなどの過度なモードを避けるか、LifeUp を関連する許可リストに追加。

<br/>

**それでも動作しない場合**

ユーザー報告と当社のテストに基づくと、正しく設定すれば LifeUp は主流端末で正常に動作します。ただし、システムアップデートにより設定項目が移動または名称変更される場合があります。

1. 上記のすべての手順を再確認し、見落とした設定を追加。

   a. Phone Manager の制限は複数ページに分散していることが多く、標準の App 権限として一覧表示されません。

   b. 任意の手順（例：常駐通知の有効化）を試し、再度テスト。

   c. システム設定でバッテリー最適化、バックグラウンド制限、自動起動、ポップアップ／バックグラウンド表示のオプションを検索。

   d. リマインダーだけが必要な場合は、`カレンダーリマインダー` モードを試してください。

2. 同じ端末ブランド／モデルの他のユーザーにコミュニティで質問し、OS バージョンを記載。

3. 端末メーカーのサポートに連絡し、特定の App がバックグラウンドで終了されないようにする方法を確認。

---

### App ウィジェットが動作しない

1. まず LifeUp を開き、しばらくフォアグラウンドで実行し続ける。
2. ウィジェットを再追加（必要に応じて複数回試す）。
3. 後で再び失敗する場合は、このガイドを見直し、常駐設定を再確認。
4. サードパーティランチャーを使用している場合は、システムランチャーに切り替えてテスト。
5. カスタムテーマを使用している場合は、デフォルトのシステムテーマに切り替えてテスト。
6. 端末を再起動。
7. 別のランチャーで試し、ランチャー固有の問題を切り分け。
