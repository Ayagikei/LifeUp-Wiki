## ✨Мультиплатформа: десктоп

![](_media/191/04.png)

![](_media/191/05.png)

За это время мы также попробовали кое-что новое — с новым обновлением API стало возможно запрашивать различные детальные данные списков.

Мы разработали **полностью открытое (https://github.com/Ayagikei/LifeUp-Desktop)** LAN-десктопное ПО, которое подключается к телефону, отображает различные данные списков и поддерживает простые операции: покупка товаров, завершение задач, экспорт изображений размышлений и просмотр через системный просмотрщик изображений.

ПО теоретически поддерживает Windows, Linux и macOS.



⚠ Обратите внимание: десктоп пока на ранней стадии разработки.

Мы продолжим поддержку и добавление функций: создание задач через десктоп, адаптация интерфейса для взаимодействия, экспорт размышлений в markdown и т. д.

### 📝Как использовать

Подробности см. в разделе «Боковая панель → Настройки → Лаборатория → LifeUp Cloud».

Также см. наш документ: [LifeUp Desktop🖥 (lifeupapp.fun)](https://docs.lifeupapp.fun/en/#/guide/api_desktop).





## ✏️API: запрос полных данных списков и другие API

![](_media/191/06.png)

**Интерфейс данных**

Как основа данных для десктопного клиента, в этой версии мы предоставляем полный интерфейс запроса данных.

Если вы Android-разработчик, можно использовать наш **LifeUp SDK** для запроса различных данных в App LifeUp.

Для других типов разработчиков можно использовать HTTP-протокол для вызова API «LifeUp Cloud». Так же поступает десктопный клиент.

Если вы не разработчик — не беспокойтесь:

1. Сейчас — лучшая возможность для обучения.

2. Перечисленные API открыты — значит, разработчики сообщества могут использовать эти данные для вторичной разработки.

Например, они могут проектировать страницы списков задач, страницы магазина и выполнять более сложную вторичную разработку (скидки, функции покупки/продажи репы и т. д.).

Результаты вторичной разработки также могут принести пользу всем пользователям.



Конкретные интерфейсы будут добавлены в документацию API позже.

**Другие улучшения API**

Добавления

- Внесение и снятие через банкомат
- Установка «Запретить покупку» для предметов
- Установка «Цвет метки» для задач
- Прямая установка баланса банкомата
- Простой запрос деталей указанного предмета
- Добавление третьей кнопки и опции операции в интерфейс «confirm_dialog»

Изменения поведения

- API всплывающего окна confirm_dialog: если текст или операция некоторых кнопок не указаны, кнопка не отображается.

  Это даёт большую гибкость управления всплывающими окнами — например, можно создать текстовое окно без кнопок для отображения текста и мотивации.

- API штрафа penalty: в прошлых версиях можно было списать максимум 100 предметов, теперь лимит расширен до 9 цифр.

### 📝 Использование

См. нашу документацию API и репозиторий GitHub:

[LifeUp Cloud☁️ (lifeupapp.fun)](https://docs.lifeupapp.fun/en/#/guide/api_cloud)

https://github.com/Ayagikei/LifeUp-SDK

## 🚀Прочее: оптимизация производительности

По отзывам пользователей и данным онлайн мы обнаружили, что эффективность некоторых запросов данных в App LifeUp значительно снижается при большом объёме данных.

Для приложения списка дел стабильность и долгосрочность критически важны.

Поэтому в этой версии мы провели серию оптимизаций для сценариев с большим объёмом данных. Эти оптимизации могут значительно ускорить загрузку большинства страниц списков (особенно страницы списка задач).

Мы продолжим оптимизацию для таких сценариев.

2. Исправлены некорректные отступы для адаптивных иконок.
3. Оптимизировано отображение записей таймера Pomodoro.
4. Улучшено взаимодействие при восстановлении резервной копии.

6. Подсказка отключить функцию импорта в один клик, если выбранный файл резервной копии не из LifeUp при прямом импорте из файловой системы.
7. Автоматическое закрытие метода ввода при поиске товаров во всплывающем окне выбора товаров.

**🐛Исправления ошибок**

1. Исправлена проблема, когда страница таймера Pomodoro в конце показывала «загрузку» в определённых обстоятельствах.
2. Исправлены сбои, вызванные некоторыми сторонними библиотеками.
3. Исправлен сбой App при размещении таймера Pomodoro в нижней панели навигации из-за всплывающей подсказки.
4. Исправлено аномальное отображение значений атрибутов при просмотре профилей других пользователей.
5. Исправлена проблема, когда события API и уведомления о понижении уровня атрибутов отправлялись некорректно.
6. Исправлены некоторые проблемы взаимодействия на страницах редактирования по долгому нажатию.
7. Исправлены некоторые аномальные отступы на страницах управления изображениями и синтеза.
8. Исправлены некоторые всплывающие окна без прокрутки, что вызывало аномальное использование в альбомной ориентации.

## 4-я годовщина

Надеемся, вам понравится обновление!

Прошло 4 года с начала разработки LifeUp, и мы продолжим приносить больше обновлений и оптимизаций.

Но мы также понимаем, что разовая покупка не очень дружелюбна к долгосрочной поддержке App. Но не беспокойтесь — мы тоже сторонники разовой покупки.

Если LifeUp вам помогает и вы готовы «купить разработчикам кофе» на странице «О приложении» или рекомендовать LifeUp друзьям и сообществам — это всё поможет нашей долгосрочной поддержке и приблизит нас к полноценной разработке.
