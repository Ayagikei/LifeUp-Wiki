## 1. ✅Награды несколькими предметами

![image-20240422223851277](_media/194/image-20240422223851277.png)

Теперь в LifeUp можно выбирать несколько предметов в разных местах. Больше не нужно настраивать открытие сундуков или синтез для получения нескольких наград.

Например:

- Напрямую задавать несколько предметов в награду за задачу
- Выбирать несколько предметов при настройке открытия сундука и сразу задавать вероятности
- Напрямую задавать несколько предметов в награду за достижения и подзадачи

<br/>

### 📕Как использовать?

Нажмите кнопку множественного выбора вверху при выборе предметов.

> Обратите внимание: в некоторых сценариях поддерживается только одиночный выбор.

![image-20240422223906505](_media/194/image-20240422223906505.png)

## 2. 🔧Виджеты инвентаря

![widget_inventory_large_preview](_media/194/widget_inventory_large_preview.png)

В этой версии добавлены два размера виджетов инвентаря.

Теперь можно напрямую просматривать и быстро использовать предметы из инвентаря с рабочего стола.

<br/>

### 🚀 Оптимизации и решение проблем

Несмотря на запуск виджета магазина несколько версий назад, мы постепенно сталкивались с сбоями и другими проблемами.

Например, из-за ограничений системы виджетов слишком большое количество предметов могло вызывать сбой App, проблемы переключения списков или сбои загрузки пользовательских изображений.

В этой версии мы нашли подходящие решения. Теперь виджеты магазина и инвентаря должны корректно отображать большое количество предметов — мы протестировали виджет магазина с почти 1000 предметами, и он остаётся работоспособным (хотя это не рекомендуется).

<br/>

### 📕Как использовать?

Обычно виджет можно создать долгим нажатием на системный рабочий стол.

Если вы используете устройство Xiaomi или Redmi (MIUI/HyperOS), добавление виджетов в MIUI/HyperOS несколько скрыто — см. документ о конфигурации совместимости.

## 3. ✨Другие функции

**Темы интерфейса**

![image-20240422223925926](_media/194/image-20240422223925926.png)

1. Пользовательские цвета (текста задач, предметов) теперь включают больше предустановленных значений
2. Адаптация к монохромной адаптивной иконке Android 14
3. Добавлена адаптация для большего числа языков (версия Google Play)

**Достижения**

![image-20240422223959899](_media/194/image-20240422223959899.png)

1. Если есть достижения с невостребованными наградами, в списке достижений теперь отображается маленькая красная точка.

**Задачи**

![image-20240422224026331](_media/194/image-20240422224026331.png)

1. Подзадачи штрафных задач теперь корректно выполняют логику штрафа
2. Добавлено «Умное управление часовым поясом» — если вы работаете в разных часовых поясах, LifeUp поддерживает автоматическое определение смены часового пояса и глобальную корректировку времени
3. Основа статистики на странице деталей теперь запоминает последний выбор, оптимизированы некоторые значения по умолчанию
4. Оптимизирована обработка серии дней непрерывного выполнения задач на странице «Мой профиль» — если вы забыли выполнить задачу один день, наверстать можно без прерывания серии

**Атрибуты**

![image-20240422224041201](_media/194/image-20240422224041201.png)

1. Поддержка удаления записей об опыте
2. Поддержка сброса опыта отдельного атрибута

**Виджеты**

1. Теперь нажатие на пустую область в виджетах магазина или инвентаря сразу открывает список, на который указывает виджет, а не последний список
2. Виджеты задач теперь отображают прогресс задач со счётчиком

**API**

1. Добавлен API редактирования записей Pomodoro
2. API завершения задач теперь корректно обрабатывает штрафные задачи
3. API завершения задач теперь поддерживает обработку задач со счётчиком (добавлен параметр `count`)
4. API завершения задач поддерживает параметр коэффициента награды
5. API изменения предметов поддерживает изменение id списка предметов
6. API создания и изменения предметов поддерживает параметр критерия сортировки
7. Jump API поддерживает переход к всплывающему окну использования предмета
8. Унифицированы некоторые определения параметров, напр. `itemId` → `item_id`
9. Добавлены широковещательные уведомления о запуске, паузе и завершении секундомера
10. В API изменения предметов `title_color_string` теперь поддерживает пустую строку для восстановления значения по умолчанию
11. Широковещание завершения задач теперь включает id списка
12. Открытие сундуков и синтез теперь также вызывают широковещание использования предмета

Помимо этого, мы исправили большое количество проблем и ошибок, о которых сообщали в последнее время.

### ♻️Оптимизации

1. При добавлении или редактировании задач теперь выводится предупреждение, если не выбран атрибут, но введён опыт
2. Оптимизированы записи повторных попыток загрузки
3. Оптимизировано отображение заголовка и ограничения ввода на странице пользовательских уровней
4. Оптимизирована производительность и проблемы с таймингом при отмене задач, многократно повторённых
5. Рефакторинг всплывающего окна использования предмета, логики интерфейса календаря и т. д.
6. Оптимизирована логика напоминаний о задачах — напоминания из удалённых или прежних данных не отправляются повторно
7. Оптимизирован текст ожидания в интерфейсе резервного копирования
8. Изображения, выбранные на странице пользовательских атрибутов, теперь также добавляются в историю выбора
9. При редактировании записей Pomodoro теперь пытается корректировать (увеличивать или уменьшать) нужное количество помидоров

### 🐛Исправления ошибок

1. Исправлено системное достижение, связанное со статистикой и резервными копиями, которое не срабатывало после реструктуризации
2. Исправлены потенциальные конфликты виджетов random API и toast API со стандартным toast
3. Исправлено отсутствие обновления деталей задачи в некоторых сценариях при входе из виджета
4. Исправлена возможность ошибок при многократном открытии сундуков в особых ситуациях (преждевременное расходование инвентаря)
5. Исправлена проблема отсутствия подзадач на странице деталей после редактирования задачи без подзадач и добавления новых
6. Исправлены некоторые случаи, когда невозможно было редактировать награды монетами
7. Исправлены некоторые случаи, когда получение командных предметов могло не работать
8. Исправлены аномалии стиля MD2 в некоторых нижних всплывающих окнах
9. Исправлены потенциально неверные значения дополнительного времени в таймерах Pomodoro
10. Исправлена проблема, когда полоска цвета в виджете изменения опыта могла не отображаться
11. Исправлено некорректное отображение некоторых задач в календаре «в процессе»
12. Исправлены некоторые проблемы загрузки списков на страницах истории и чувств
13. Исправлена проблема, когда двойной вызов API завершения задачи подряд не позволял выполнить два последовательных завершения
