# Запрос на удаление данных для *LifeUp Lite*

## 1. Хранение и удаление данных

LifeUp Lite, бесплатная версия LifeUp, в основном хранит данные на устройстве пользователя. Мы ценим вашу конфиденциальность и автономию.

В LifeUp Lite, поскольку учётные записи не создаются, все персональные данные хранятся локально на вашем устройстве.

**Чтобы удалить эти данные, просто удалите приложение LifeUp Lite с устройства. При удалении все локально сохранённые данные будут безвозвратно удалены.**

## 2. Сторонние сервисы

LifeUp Lite интегрируется со сторонними сервисами, такими как Firebase и Admob, для функциональности и рекламы.

Обратите внимание: данные, собираемые этими сервисами, не включают персональную информацию, связанную с вашей личностью, и используются в соответствии с их политиками конфиденциальности.

Эти данные автоматически удаляются через определённый период согласно политикам этих сервисов.

## 3. Помощь с удалением данных

Если вам нужна помощь или есть вопросы об удалении данных, напишите нам на lifeup@ulives.io.

Наша команда готова помочь с любыми вопросами о конфиденциальности данных и при необходимости проведёт вас через процесс.

## 4. Соответствие и обновления

Мы постоянно пересматриваем и обновляем практики для соответствия актуальным нормам и отраслевым стандартам. Этот раздел политики конфиденциальности будет обновляться по мере изменений в управлении и удалении данных.
