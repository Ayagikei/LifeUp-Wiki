# Запрос на удаление данных для *LifeUp Pro*

## 1. Удаление данных в LifeUp Pro

Пользователи LifeUp Pro могут самостоятельно удалять свои данные в приложении.

Поскольку LifeUp Pro в основном офлайн-приложение, вы управляете данными прямо на устройстве.

Чтобы удалить данные, выполните следующие шаги:

1. В LifeUp Pro откройте `Настройки` → `Бэкап/Восстановление/Удаление данных` (`Бэкап/Восстановление`), затем `Очистка данных и удаление аккаунта`.
2. Выберите `Очистить данные об опыте`, `Очистить данные о монетах`, `Очистить данные системных достижений`, `Очистить данные истории` или `Удалить локальные данные`.
3. Подтвердите. Очистка опыта, монет, системных достижений и истории оставляет App открытым. `Удалить локальные данные` ждёт 15 секунд, удаляет базу данных, настройки и медиа, возвращает App к состоянию первой установки и перезапускает его. Сначала сделайте резервную копию вручную.

**Также удаление LifeUp Pro с устройства приведёт к удалению всех локально сохранённых данных.**



## 2. Удаление учётной записи в LifeUp Pro

Удаление учётной записи — отдельный процесс от удаления данных.

При удалении учётной записи будут удалены:

- Ваши публичные публикации, например команды и обновления, на наших серверах.
- Ваш никнейм и другая персональная информация, связанная с учётной записью.
- OAuth-связи, привязанные к учётной записи.

**Чтобы удалить учётную запись LifeUp Pro, выполните ранее описанные шаги:**

1. Откройте `Настройки` → `Бэкап/Восстановление/Удаление данных`, затем `Очистка данных и удаление аккаунта`.
2. Нажмите `Удалить аккаунт (удаленные данные)`.
3. Подтвердите после 30-секундного отсчёта, чтобы удалить данные этого аккаунта на серверах LifeUp. Сначала сделайте резервную копию вручную. Задачи и другие локальные данные остаются на устройстве.

<br/>

**Если вы больше не используете LifeUp Pro, но хотите удалить учётную запись и персональные данные, свяжитесь с нами: [lifeup@ulives.io](mailto:lifeup@ulives.io).**

Предоставьте необходимые сведения об учётной записи — наша команда поможет с процессом удаления.

Мы обеспечиваем конфиденциальность и обрабатываем ваш запрос с максимальной осторожностью.



## 3. Сторонние сервисы

Как и LifeUp Lite, LifeUp Pro интегрируется со сторонними сервисами, такими как Firebase, для расширенной функциональности. Собираемые данные не позволяют идентифицировать личность и управляются в соответствии с их политиками конфиденциальности. Эти данные автоматически планируются к удалению через определённый период согласно политикам сторонних сервисов.
