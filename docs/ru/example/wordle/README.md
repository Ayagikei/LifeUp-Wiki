# Клон Wordle

Создан с помощью HTML, CSS и JavaScript

Чтобы играть, [нажмите здесь](https://thejasnu.github.io/wordle-clone/)

-   CSS Grid используется для клавиатуры и плиток с буквами
-   transition и animation для эффектов тряски и «танца»
-   Список слов взят с официального сайта New York Times
