## Community-Beiträge 🤝

Wir sind der Community sehr dankbar für Tools, die LifeUp erweitern. Unten findest du offizielle Toolkits und ausgewählte Community-Projekte.

## Offizielle Toolkits

| Projekt | Beschreibung |
| --- | --- |
| [LifeUp Cloud](guide/api_cloud.md) | HTTP-API-Bridge auf dem Telefon; LAN-Zugriff und **QR-Scan** (`lifeup://`, Web-URLs, andere App-Schemes) |
| [@lifeup/mcp](guide/api_mcp.md) | Offizieller MCP-Server + Skills für Cursor, Claude Desktop und andere KI-Agenten über LAN |
| [LifeUp Desktop](guide/api_desktop.md) | Offizieller Desktop-Client auf Basis von LifeUp Cloud HTTP |
| [Wordle-Integrationsdemo](example/wordle/index.html) | Wortratespiel; ruft bei Sieg `lifeup://api/reward` auf |

**Wordle-Einrichtung:** Shop-Gegenstand anlegen → Link-Effekt Typ 9 auf die Wordle-Seite → **Verwenden** öffnet das Spiel im Browser; Sieg gibt 10 Münzen, Niederlage trotzdem eine Trost-Münze. Die Wordle-URL kann auch als QR-Code kodiert und mit LifeUp Cloud gescannt werden. Siehe [API · Externes Web (Wordle)](guide/api.md).
