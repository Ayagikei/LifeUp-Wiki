## مقدمة
هذا أول إصدار في 2025، ويتضمن التحديثات الرئيسية التالية:

- دعم أيقونات Emoji: يمكنك الآن استخدام Emoji مباشرة كأيقونات للعناصر والإنجازات وغيرها.

- الموجة الثانية من تحديثات API: تدعم واجهات API الآن تعديل المهام وتحرير تأثيرات العناصر وشروط فتح الإنجازات والتركيب وعمليًا كل الوظائف الأساسية.

- تحسين LifeUp Cloud وعميل سطح المكتب: تحسين تجربة اكتشاف الاتصال التلقائي؛ يضيف عميل سطح المكتب ميزة «مشاعر جديدة» ويدعم استيراد/تصدير بيانات النسخ الاحتياطي.

## II. الموجة الثانية من تحديثات API
![image-20250106212817689](./_media/198/image-20250106212817689.png)

منذ فتح وظائف API في v1.90.0، يسعدنا رؤية العديد من المستخدمين يستكشفون API بنشاط وينشئون محتوى غنيًا. بدأ كثيرون من الصفر بتعلّم معرفة URL ونجحوا في تطبيق API لإنشاء widgets لسطح المكتب وعملاء سطح مكتب DIY، بل ودمج تطبيقات الويب — وهذا مثير للإعجاب.

لكن بسبب هياكل البيانات المعقدة وحجم عمل التصميم والتطوير الكبير، افتقر الإصدار الأول من APIs إلى بعض الوظائف الأساسية، مثل تحرير المهام وتحرير العناصر وإنشاء إنجازات بشروط فتح وإنشاء عناصر بتأثيرات استخدام. استمر إكمال هذه الميزات حتى هذا الإصدار.

جلب تصميم وتطوير واختبار وتحديث السحابة وعملاء سطح المكتب ووثائق API عبئ عمل يتزايد بشكل أسي، ما جعل فرع التطوير الذي بدأ قبل عدة أشهر يكمل التطوير والاختبار الآن فقط.

**لكن جهودنا أثمرت! اليوم، يغطي API تقريبًا كل الوظائف الأساسية في LifeUp. بفتح API، نأمل أن يكون LifeUp أكثر من مجرد App — منصة مفتوحة حيث يمكن للمستخدمين تطوير أنظمة gamification الخاصة بهم وتوسيعها وتخصيصها بحرية.**

### 📕كيفية الاستخدام؟

- لطرق استخدام API، راجع مكتبة الوثائق → الدليل → قسم الواجهة المفتوحة.
- أُضيفت تعريفات واجهات API الجديدة إلى الوثائق.

## III. عميل سطح المكتب: الأرشيف والمشاعر

### الأرشيف

![image-20250106212442295](./_media/198/image-20250106212442295.png)

يمكنك الآن تصدير أو استيراد ملفات النسخ الاحتياطي مباشرة على عميل سطح المكتب.

سيُبسّط ذلك نقل البيانات إلى أجهزة أخرى والاستعادة.

### نشر مشاعر جديدة

![image-20240927225309975](./_media/198/image-20240927225309975.png)

يدعم الآن نشر مشاعر جديدة من عميل سطح المكتب، مع دعم كامل لإضافة الصور وضبط ميزات الوقت.

⚠️ملاحظة: تحرير المشاعر غير مدعوم بعد.

### تحديثات أخرى

- تحسين رسائل الأخطاء والشروحات المتعلقة بالاتصال: توضيح ما إذا كانت المشكلة شبكية أم بسبب عدم تشغيل backend الخاص بـ LifeUp
- دعم عرض تفاصيل المهام
- دعم التحقق الأمني من API Token (اختياري، يتطلب LifeUp Cloud 2.0.0)
- منطق الشراء يستخدم الآن «purchase item API» الجديد بدل «adjust item quantity API» + «adjust coin amount API» السابقين. يمكنه الآن معالجة منطق حد الشراء بشكل صحيح، مع الحفاظ على الاتساق مع App.

يعمل هذا التحديث أيضًا على إظهار قدرات API عبر عميل سطح المكتب، إذ تُنفَّذ كل ميزات عميل سطح المكتب عبر API.

## IV. تحسين LifeUp Cloud

> LifeUp Cloud أداة تعرض API كواجهات HTTP وتعمل كجسر لاتصال عميل سطح المكتب.

![image-20250106212715220](./_media/198/image-20250106212715220.png)

![image-20250106212725277](./_media/198/image-20250106212725277.png)

أجرينا تحسينات عديدة بناءً على ملاحظات حول LifeUp Cloud:

- إضافة عرض الحالة لاكتشاف سبب عدم اتصال عميل سطح المكتب بسرعة
- إضافة إعدادات متقدمة
  - السماح بالوصول عبر المصادر المختلفة: مفيد للوصول إلى واجهات HTTP الخاصة بـ LifeUp Cloud باستخدام تقنيات الويب
  - السماح بمنافذ خدمة مخصصة
  - السماح بتعيين access tokens: إجراء تحقق أمني اختياري
- تحسين قيم الأخطاء المُرجعة ومواصفات واجهات LifeUp Cloud
- تحسين منطق اكتشاف الخدمة والتبديل بين خدمات HTTP؛ يجب أن يعمل الاكتشاف التلقائي لعميل سطح المكتب بشكل أفضل الآن

## V. معاينة

بما أن هذا التحديث يجلب ميزات غير API قليلة نسبيًا، إليك معاينة لمحتوى الإصدارات القادمة، بما في ذلك الميزات قيد التطوير حاليًا:

- **ميزة رئيسية:** إنجازات قابلة للتكرار
- **ميزة متوسطة:** تحسين قراءة النص للخلفيات المخصصة
  - ظننا في البداية أنها تغيير بسيط، لكنها تبيّنت معقدة
- **ميزة ثانوية:** إضافة إجراءات «إكمال» و«تذكير لاحق» إلى الإشعارات
  - كان مخططًا دعم الإشعارات المستمرة، لكن تُرك لأن إصدارات Android الأحدث لم تعد تدعم الاستمرارية الحقيقية
