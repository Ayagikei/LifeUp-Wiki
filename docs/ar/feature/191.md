![](_media/191/05.png)

طوّرنا **برنامج سطح مكتب LAN مفتوح المصدر بالكامل（https://github.com/Ayagikei/LifeUp-Desktop）** يمكنه الاتصال بهاتفك وعرض بيانات قوائم متنوعة، ويدعم بعض العمليات البسيطة: شراء منتجات، إكمال مهام، تصدير صور التأمل وعرضها بمتصفح صور النظام.

## ✏️API: استعلام بيانات القائمة الكاملة و APIs إضافية

![](_media/191/06.png)

**واجهة البيانات**

باعتبارها أساس مصدر البيانات لعميل سطح المكتب، نقدّم في هذا الإصدار واجهة استعلام بيانات كاملة.

إذا كنت مطور Android، يمكنك استخدام **LifeUp SDK** للاستعلام عن بيانات متنوعة في LifeUp App.

إذا كنت أي نوع آخر من المطورين، يمكنك استخدام بروتوكول HTTP لاستدعاء API «LifeUp Cloud». هذا أيضًا الممارسة على عميل سطح المكتب.

إذا لم تكن تعرف التطوير، لا تقلق:

1. أولًا، الآن أفضل فرصة للتعلّم.

2. ثانيًا، APIs البيانات أعلاه مفتوحة، ما يعني أن مطوري المجتمع يمكنهم استخدام هذه البيانات للتطوير الثانوي.

على سبيل المثال، يمكنهم تصميم صفحات قائمة مهام وصفحات متجر، وإجراء تطوير ثانوي أكثر تعقيدًا (مثل الخصومات ووظائف شراء/بيع turnip).

يمكن أن تفيد نتائج التطوير الثانوي جميع المستخدمين.



ستُضاف الواجهات المحددة إلى وثائق API لاحقًا.

**تحسينات واجهات API الأخرى**

إضافات

- إيداع وسحب ATM
- تعيين «Disable Purchase» للعناصر
- تعيين «Tag Color» للمهام
- تعيين رصيد ATM مباشرة
- استعلام بسيط لتفاصيل عنصر محدد
- إضافة زر ثالث وخيار عملية إلى واجهة «confirm_dialog»

تغييرات السلوك

- confirm_dialog pop-up API، إذا لم يُوفَّر نص أو عملية بعض الأزرار، لن يُعرض الزر.

  يوفر ذلك مرونة أعلى في التحكم بالنوافذ المنبثقة؛ على سبيل المثال، يمكنك تعيين نافذة منبثقة نصية فقط بلا أزرار لعرض نص وعبارات تحفيزية.

- penalty punishment API، في الإصدارات السابقة، كان الحد الأقصى لخصم العناصر 100، ورفعنا الحد الآن إلى 9 أرقام.

### 📝 الاستخدام

راجع وثائق API ومستودع GitHub:

[LifeUp Cloud☁️ (lifeupapp.fun)](https://docs.lifeupapp.fun/en/#/guide/api_cloud)

https://github.com/Ayagikei/LifeUp-SDK

## 🚀أخرى: تحسين الأداء

من خلال ملاحظات المستخدمين وجمع البيانات عبر الإنترنت، وجدنا أن كفاءة بعض استعلامات البيانات في LifeUp App تنخفض بشكل ملحوظ مع كمية بيانات كبيرة.

بالنسبة لتطبيق قائمة مهام، الاستقرار والاستدامة أمران حاسمان.

لذلك، في هذا الإصدار، أجرينا سلسلة تحسينات لسيناريوهات البيانات الكبيرة. يمكن لهذه التحسينات تحسين سرعة تحميل معظم صفحات القوائم بشكل كبير (خاصة صفحة قائمة المهام).

سنواصل التحسين لهذه السيناريوهات.
