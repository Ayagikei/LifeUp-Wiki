#### ⏰تصفية الوقت

![image-20230716005914025](_media/192/image-20230716005914025.png)

يجب أن يكون LifeUp مخصّصًا لك؛ لا يلزم الانتظار حتى نهاية العام لرؤية الملخص السنوي، ولا داعي للقلق من فقدان الملخص السنوي كل عام.

في LifeUp، يمكنك الوصول إلى **ملخصات سنوات ماضية** في أي وقت. هل أنت فضولي حول بيانات ملخصك السنوي لـ 2022~ حدّث وجرّب!

## 🖥️سطح المكتب

### ✨اتصال تلقائي

![image-20230716020204259](_media/192/image-20230716020204259.png)

![image-20230716020210438](_media/192/image-20230716020210438.png)


وفقًا لملاحظات المستخدمين، ملء IP عامل رئيسي يعيق استخدام نسخة سطح المكتب.

يجلب هذا التحديث وظيفة اكتشاف IP تلقائيًا لـ LifeUp Cloud Server.

<br/>

المتطلب المسبق لاستخدام هذه الوظيفة:

- تنزيل v1.3.0 من LifeUp Cloud (يمكنك الحصول عليه من تحديثات Google Play أو صفحات GitHub لدينا).

يمكنك اكتشاف عنوان IP المقابل تلقائيًا على نسخة سطح المكتب، دون الحاجة لملئه يدويًا بعد الآن.

> بعد الاختبار، هذه الميزة مُتحقَّق منها حاليًا أساسًا على جانب Windows.
>
> جانب macOS قد لا يدعم الاكتشاف التلقائي بعد.

### 🚀**تصدير المشاعر إلى markdown**

![image-20230716020241251](_media/192/image-20230716020241251.png)

![image-20230716020226764](_media/192/image-20230716020226764.png)

تدعم نسخة سطح المكتب الآن تصدير المشاعر بصيغة markdown.

وتدعم التجميع والتصدير بطرق متعددة، وستتضمن الانطباعات مرفقات صور كاملة.

بصيغة markdown، يمكنك بسهولة استخدام **أدوات طرف ثالث** للعرض والتحويل إلى pdf و word وصيغ أخرى.

------

### **✏️إضافة مهمة**

![image-20230716020407513](_media/192/image-20230716020407513.png)

بمساعدة قدرات API المبنية سابقًا، تدعم نسخة سطح المكتب الآن إنشاء مهام بسيطة.

الإعدادات الحالية لم تغطِّ كل الخيارات في App بعد، لكنها كافية لإنشاء مهام بسيطة.

ستواصل الإصدارات اللاحقة تعزيز خيارات إنشاء المهام ودعم تحرير المهام وغيرها.

### 🖥️**حزمة تثبيت macOS**

بدءًا من الإصدار 1.1.0، سنبدأ أيضًا إصدار حزم تثبيت macOS.

بعد اختبار بسيط، وظائف نسخة Mac OS تعمل بشكل أساسي طبيعي.

للتفاصيل، راجع أيضًا [🖥LifeUp Desktop (lifeupapp.fun)](https://docs.lifeupapp.fun/en/#/guide/api_desktop)
