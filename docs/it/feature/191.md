## v1.91.0 - Widget stato, gradiente Livello personalizzato, desktop semplice

> [DEV] Novità in v1.91: widget stato, gradiente Livello personalizzato, desktop semplice

> Presentiamo l'aggiornamento v1.91. Grazie ai maintainer a lungo termine della community Reddit LifeUp! :D Non abbiamo risorse sufficienti per seguire tutte le community, quindi gestiamo soprattutto feedback da 📧 e GitHub. Per domande o suggerimenti: 📫[lifeup@ulives.io](mailto:lifeup@ulives.io) o issue su GitHub (https://github.com/Ayagikei/LifeUp/issues).

Ci scusiamo per l'attesa lunga.

Per vari motivi, lo sviluppo e l'apprendimento sono rallentati dalla fine dell'anno. Con il vostro supporto ho anche aggiornato l'attrezzatura di sviluppo e montato un desktop, rendendo sviluppo, debug e release più efficienti.



Di recente siamo tornati al ritmo di aggiornamento normale. La v1.91 porta aggiornamenti secondo la precedente «roadmap di sviluppo». **v1.91 viene rilasciata gradualmente: se non avete ancora l'aggiornamento, attendete un po'.**



Avevamo pianificato Google Calendar integrato in v1.91, ma nel processo di sviluppo abbiamo incontrato molti ostacoli tecnici. Per rilasciare altri aggiornamenti prima possibile, abbiamo deciso di rimandarlo e concentrarci su altre funzioni prima di tornare all'integrazione Google Calendar. Ci scusiamo con chi si aspettava Google Calendar in v1.91, ma continueremo a lavorarci.



Abbiamo anche provato qualcosa di nuovo: lo sviluppo di un client desktop LAN. **Nota: il client desktop è ancora molto rudimentale e dipende dai dati del telefono.**

## ✨Multi-piattaforma: desktop

![](_media/191/04.png)

![](_media/191/05.png)

In questo periodo abbiamo anche provato qualcosa di nuovo e, con l'aggiornamento API, abbiamo reso possibile interrogare vari dati dettagliati degli elenchi.

Abbiamo sviluppato un software desktop LAN **completamente open source (https://github.com/Ayagikei/LifeUp-Desktop)** che si collega al telefono, mostra vari elenchi e supporta alcune operazioni semplici: acquistare prodotti, completare Compiti, esportare immagini Riflessioni e visualizzarle con il browser immagini di sistema.

Il software supporta teoricamente Windows, Linux e macOS.



⚠️ Nota: il desktop è ancora in fase iniziale.

Continueremo a mantenerlo e ad aggiungere funzioni, come creare Compiti dal desktop, adattare l'interfaccia, esportare Riflessioni in markdown, ecc.

### 📝Come usare

Per i dettagli, vedi «Barra laterale → Impostazioni → Labs → LifeUp Cloud».

Consulta anche la documentazione: [LifeUp Desktop🖥 (lifeupapp.fun)](https://docs.lifeupapp.fun/en/#/guide/api_desktop).





## ✏️API: query dati elenco completi e altre API

![](_media/191/06.png)

**Interfaccia dati**

Come base dati per il client desktop, in questa versione forniamo un'interfaccia di query dati completa.

Se sei uno sviluppatore Android, puoi usare il **LifeUp SDK** per interrogare vari dati nell'App LifeUp.

Per altri tipi di sviluppatore, puoi usare HTTP per chiamare l'API «LifeUp Cloud», come fa il client desktop.

Se non conosci lo sviluppo, niente panico:

1. Ora è il momento migliore per imparare.

2. Le API dati sopra sono aperte: gli sviluppatori community possono usarle per sviluppo secondario.

Ad esempio possono progettare pagine elenco Compiti, pagine Negozio e sviluppo secondario più complesso (sconti, funzioni tipo «compravendita navet»).

I risultati dello sviluppo secondario possono avvantaggiare tutti gli utenti.



Le interfacce specifiche verranno aggiunte alla documentazione API più avanti.

**Altri miglioramenti API**

Aggiunte

- Deposito e prelievo ATM
- Impostare «Disabilita acquisto» per Oggetti
- Impostare «Colore tag» per Compiti
- Impostare saldo ATM direttamente
- Query semplice dettagli Oggetto specificato
- Aggiunto terzo pulsante e opzione operazione all'interfaccia «confirm_dialog»

Modifiche comportamento

- API popup confirm_dialog: se testo o operazione di alcuni pulsanti mancano, il pulsante non viene mostrato.

  Maggiore flessibilità nei popup, ad esempio popup solo testo senza pulsanti per messaggi motivazionali.

- API penalità: nelle versioni passate si potevano dedurre al massimo 100 Oggetti; ora il limite è esteso a 9 cifre.

### 📝 Utilizzo

Consulta documentazione API e repository GitHub:

[LifeUp Cloud☁️ (lifeupapp.fun)](https://docs.lifeupapp.fun/en/#/guide/api_cloud)

https://github.com/Ayagikei/LifeUp-SDK

## 🍅Pomodoro: timing automatico lavoro e pausa

![screely-1676558398757](_media/191/07.png)

Questa versione introduce anche l'avvio automatico del timer Pomodoro.

Assicurati che il telefono abbia la **configurazione di compatibilità** per evitare che il sistema interrompa il Pomodoro.

Nota: attivando «Avvio automatico pausa», la funzione countdown aggiuntivo originale viene disabilitata.

### 📝 Utilizzo

Vai a Pomodoro → Impostazioni in alto a destra.

## 🚀Altro: ottimizzazione prestazioni

Da feedback utenti e dati online abbiamo visto che l'efficienza di alcune query dati in LifeUp cala molto con grandi volumi.

Per un'App todo, stabilità e uso a lungo termine sono cruciali.

In questa versione abbiamo ottimizzato scenari con molti dati, migliorando sensibilmente il caricamento della maggior parte delle pagine elenco (soprattutto Compiti).

Continueremo a ottimizzare questi scenari.

**1.91.0-alpha01 (2023/02/13)**

1. Supporto gradienti Livello personalizzati.

   - Depositi e prelievi ATM.

   - Terzo pulsante e opzione operazione nell'interfaccia popup.

**♻️Ottimizzazioni**

1. Migliorate velocità query, elaborazione e prestazioni con grandi quantità di dati.
2. Corretti margini errati per icone adattive.
3. Ottimizzato display record timer Pomodoro.
4. Migliorata interazione al ripristino backup.
5. Aggiunta UI per ottenere licenza tramite Google Play (versione prova gratuita GitHub).
6. Prompt per disabilitare import one-click se il file backup selezionato non proviene da LifeUp all'import diretto dal file system.
7. Chiusura automatica tastiera nella ricerca Oggetti nel popup selezione prodotto.
8. Modifiche comportamento API, inclusi:
   - API popup Confirm_dialog: se manca testo o operazione di un pulsante, il pulsante non viene mostrato. Maggiore flessibilità, ad esempio popup solo testo senza pulsanti.
   - API penalità: prima si potevano dedurre al massimo 100 Oggetti, ora il limite è esteso a 9 cifre.

**🐛Correzioni bug**

1. Corretto che la pagina Pomodoro mostrasse «caricamento» alla fine in certe circostanze.
2. Corretti crash da alcune librerie di terze parti.
3. Corretto crash mettendo il Pomodoro nella barra navigazione inferiore per un popup prompt.
4. Corretto display anomalo valori Attributo navigando profili altri utenti.
5. Corretto che eventi API e notifiche per riduzione Livello Attributo non venissero inviati correttamente.
6. Corrette alcune interazioni pagine modifica con pressione lunga.
7. Corretti margini anomali su pagine gestione immagini e Sintesi.
8. Corrette alcune finestre popup non scrollabili con uso anomalo in landscape.
