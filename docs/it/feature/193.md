## I. 📋 Modelli Compito

![image-20231023213616938](_media/193/image-20231023213616938.png)

Questa versione introduce modelli Compito integrati. Non serve più creare Compiti indirettamente con «Copia Compito» e API.

Creando o modificando Compiti, puoi salvare le impostazioni correnti come modello.

In futuro, creando Compiti, importi con un clic impostazioni Ricompense, Compito e altro.

### 📕 Come usare?

Creando o modificando Compiti, clicca il pulsante Modelli Compito nella barra superiore.

![image-20231023213703434](_media/193/image-20231023213703434.png)

I modelli registrano la maggior parte delle impostazioni, ma al momento non includono la scadenza.





## II. 🎨 Tema Material You

![image-20231023213837819](_media/193/image-20231023213837819.png)

![image-20231023213849504](_media/193/image-20231023213849504.png)

Questa versione si adatta completamente al linguaggio di design Material You (tema).

È più moderno e pulito, ed è uno degli stili UI ufficialmente promossi per il futuro.

Il cuore di Material You: «ognuno può avere un colore tema diverso».

LifeUp può introdurre colori tema dinamici da sfondo e colori personalizzati. (Nota: serve supporto del dispositivo.)

### 📕 Come usare?

Come nelle immagini, apri la barra laterale → Impostazioni → Display per le opzioni correlate.

Se il dispositivo non supporta colori tema dinamici, puoi scegliere tra colori preimpostati.

Se li supporta, abilita la funzione e personalizza i colori con alta flessibilità:

![image-20231023213903322](_media/193/image-20231023213903322.png)

## III. ✨ Altre funzioni

**Tema UI**

1. Adattamento completo a Material Design 3.
2. Personalizzazione colori tema Material Design 3: colori personalizzati, da sfondo e da immagini.
3. Migliorati alcuni effetti animazione, come i popup.
4. Ottimizzato adattamento edge-to-edge (immersivo).

**Compiti**

1. Supporto modelli Compito.
2. Statistiche pagina dettagli: switch per criteri temporali e opzioni predefinite ottimizzate.
3. Pagina cronologia: ricerca nomi Compito e UI/interazioni correlate.

**Obiettivi**

![image-20231023214451450](_media/193/image-20231023214451450.png)

1. Supporto Obiettivi segreti.
2. Aggiungendo Obiettivi, supporto «Continua ad aggiungere il prossimo Obiettivo».

**Attributi**

1. Supporto nascondere Attributi.

**Timer Pomodoro**

1. Supporto modifica record temporali.
2. Pagina Pomodoro: completamento Compito (pressione lunga sul Compito selezionato in pausa).

**Riflessioni**

1. Supporto aggiungere Riflessioni direttamente nella pagina Riflessioni.

**API**

1. Aggiunta API «use_item».
2. Aggiunta API «random».
3. Aggiunta API «edit_exp».
4. API «item» supporta parametri come «action_text», «disable_use», «title_color_string».
5. API «shop_settings» supporta parametro «silent».
6. Supporto placeholder «time»: Compiti «scadenza domani» o «prossimo mese» senza strumenti di automazione.

Oltre a queste funzioni, abbiamo affrontato vari problemi segnalati e corretto bug. Dettagli nel changelog seguente.



### ♻️ Ottimizzazioni

1. Aggiunti prefissi in alcuni punti che mostrano ID dati.
2. Ottimizzato display attività squadra.
3. Tentativo di risolvere Toast troppo lunghi per essere mostrati per intero.
4. Migliorata logica completamento widget nelle squadre, coerente con l'in-app.
5. Pagina statistiche: dopo intervallo «Personalizzato», cliccare di nuovo «Personalizzato» riapre la selezione date.
6. Compatibilità Harmony OS 4 per pulsanti azione nelle notifiche barra progresso.
7. Migliorata logica interazione richieste notifica.
8. Risolto metodo input che poteva ostruire input «Conteggio ripetizioni».
9. Creando Compiti, viene registrata la scelta di orari inizio non specifici (automatico o scadenza oggi). In modifica si ripristinano quelle opzioni, non orari specifici, per evitare discrepanze.
10. Creando Compiti, avvisi duplicati imprevisti compaiono anche nel popup «Controlla duplicati».
11. Aggiunto supporto lingua indonesiana.
12. Aggiornate traduzioni.
