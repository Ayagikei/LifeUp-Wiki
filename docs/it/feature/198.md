<h1 align="center" padding="100">v1.98.0 API 2.0 e aggiornamento client desktop</h1>


## Introduzione
Primo rilascio del 2025, con i seguenti aggiornamenti principali:

- Supporto icone Emoji: ora puoi usare Emoji direttamente come icone per Oggetti, Obiettivi e altro.

- Seconda ondata aggiornamenti API: le interfacce API supportano modifica Compiti, effetti Oggetti, condizioni sblocco Obiettivi, Sintesi e quasi tutte le funzionalità core.

- Ottimizzazione LifeUp Cloud e client desktop: migliorata rilevazione connessione automatica; il desktop aggiunge «Nuove Riflessioni» e supporta import/export dati backup.

## II. Seconda ondata aggiornamenti API
![image-20250106212817689](./_media/198/image-20250106212817689.png)

Da quando l'API è stata aperta in v1.90.0, molti utenti esplorano e creano contenuti ricchi. Molti hanno imparato da zero le URL e usato l'API per widget desktop, client DIY e persino integrazione web — impressionante.

Tuttavia, per strutture dati complesse e carico di design/sviluppo, il primo lotto API mancava funzioni core: modifica Compiti, modifica Oggetti, Obiettivi con condizioni sblocco, Oggetti con effetti uso. Il completamento è arrivato solo in questa versione.

Design, sviluppo, test e aggiornamenti di cloud, desktop e documentazione API hanno moltiplicato il carico: il branch avviato mesi fa ha completato sviluppo e test solo ora.

**Ma i nostri sforzi hanno dato frutti! Oggi l'API copre quasi tutte le funzionalità core di LifeUp. Aprendo l'API, speriamo che LifeUp sia più di un'App: una piattaforma aperta dove sviluppare, estendere e personalizzare i propri sistemi di gamificazione.**

### 📕Come usare?

- Per l'uso API, consulta la libreria documentazione → Directory → sezione Interfaccia aperta.
- Le definizioni delle nuove API sono state aggiunte alla documentazione.

### Altri aggiornamenti

- Ottimizzati messaggi e spiegazioni errori connessione: chiariscono se è un problema di rete o se il backend LifeUp non è in esecuzione
- Supporto visualizzazione dettagli Compito
- Supporto validazione sicurezza API Token (opzionale, richiede LifeUp Cloud 2.0.0)
- La logica acquisto usa la nuova API «purchase item» invece di «adjust item quantity» + «adjust coin amount». Gestisce correttamente i limiti acquisto, coerente con l'App.

Questo aggiornamento mostra anche le capacità API tramite il desktop: tutte le funzioni desktop sono implementate via API.

## IV. Ottimizzazione LifeUp Cloud

> LifeUp Cloud espone l'API come interfacce HTTP ed è il ponte per la connessione del client desktop.

![image-20250106212715220](./_media/198/image-20250106212715220.png)

![image-20250106212725277](./_media/198/image-20250106212725277.png)

Numerose ottimizzazioni in base al feedback su LifeUp Cloud:

- Aggiunto display stato per capire perché il desktop non si connette
- Aggiunte impostazioni avanzate
  - Consenti accesso cross-origin: utile per accedere alle interfacce HTTP di LifeUp Cloud con tecnologie web
  - Consenti porte servizio personalizzate
  - Consenti token di accesso: misura di sicurezza opzionale
- Ottimizzati valori errore e specifiche interfacce LifeUp Cloud
- Ottimizzati service discovery e logica switch servizio HTTP; il rilevamento automatico desktop dovrebbe funzionare meglio

## V. Anteprima

Poiché questo aggiornamento porta poche funzioni non-API, ecco un'anteprima delle prossime versioni, incluse funzioni in sviluppo:

- **Funzione principale:** Obiettivi ripetibili
- **Funzione media:** Ottimizzazione leggibilità testo su sfondi personalizzati
  - Pensavamo fosse una modifica piccola, ma si è rivelata complessa
- **Funzione minore:** Azioni completa e ricorda dopo nelle notifiche
  - Inizialmente previste notifiche persistenti, abbandonate perché le versioni Android recenti non le supportano più davvero
