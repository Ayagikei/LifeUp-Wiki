## Topluluk Katkıları 🤝

LifeUp'ın yeteneklerini genişleten araçları geliştiren topluluğumuza son derece minnettarız. Aşağıda resmi araç setleri ve öne çıkan topluluk projeleri yer alır.

## Resmi araç setleri

| Proje | Açıklama |
| --- | --- |
| [LifeUp Cloud](guide/api_cloud.md) | Telefon tarafı HTTP API köprüsü; LAN erişimi ve **QR tarama** (`lifeup://`, web URL'leri, diğer App şemaları) |
| [@lifeup/mcp](guide/api_mcp.md) | Cursor, Claude Desktop ve diğer AI ajanları için LAN üzerinden resmi MCP sunucusu + Skills |
| [LifeUp Desktop](guide/api_desktop.md) | LifeUp Cloud HTTP üzerine kurulu resmi masaüstü istemcisi |
| [Wordle entegrasyonu demosu](example/wordle/index.html) | Kelime tahmin mini oyunu; kazanınca `lifeup://api/reward` çağırır |

**Wordle kurulumu:** Mağazada bir Eşya oluşturun → Wordle sayfasına işaret eden tip-9 bağlantı efekti ekleyin → **Kullan** oyunu tarayıcıda açar; kazanç 10 jeton, kayıp yine de teselli jetonu verir. Wordle URL'sini QR kodu olarak da kodlayıp LifeUp Cloud ile tarayabilirsiniz. Bkz. [API · Harici web (Wordle)](guide/api.md).
