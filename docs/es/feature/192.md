## 📱Actualizaciones de la App Android

### 🏆Estadísticas rediseñadas

![image-20230716005706966](_media/192/image-20230716005706966.png)

![image-20230716005752274](_media/192/image-20230716005752274.png)

Las estadísticas y la revisión de datos no son solo un paso importante para mejorar nuestra productividad, sino también una fuente de inspiración y feedback.

Al revisar nuestros esfuerzos, podemos ver nuestro progreso y Logros con datos, e identificar problemas y áreas de mejora.

Para ello, hemos lanzado [Estadísticas 2.0], que te ofrece diversos datos interesantes.

<br/>

#### ❓¿Cómo usar?

![image-20230716021918105](_media/192/image-20230716021918105.png)

Para acceder a las nuevas estadísticas, actualiza a la versión v1.92.0, ve a la página [Estadísticas] y luego toca el botón [Haz clic para ver las nuevas estadísticas] en la parte superior.

<br/>

#### 📊Elementos de estadísticas

![image-20230716005738662](_media/192/image-20230716005738662.png)

Estadísticas 2.0 proporcionará análisis de datos para varios módulos: desde el porcentaje de Tareas con Enfoque en tomates, hasta el promedio de tomates por día, los cambios diarios en Atributos, los registros de compra de Objetos, el estado de completado de Tareas y más.

<br/>

#### ⏰Filtro de tiempo

![image-20230716005914025](_media/192/image-20230716005914025.png)

Y admite filtrado de rango de tiempo **flexible**; puedes ver fácilmente los datos del día, semana, mes, año o un rango personalizado.

Tu LifeUp debería adaptarse a ti; no tienes que esperar hasta fin de año para ver el resumen anual, ni preocuparte por perder el resumen anual cada año.

En LifeUp, puedes acceder a los **resúmenes anuales de años anteriores** en cualquier momento. ¿Tienes curiosidad por los datos de tu resumen anual de 2022~? ¡Actualiza y pruébalo!

<br/>

#### 👥Compartir

![image-20230716005902342](_media/192/image-20230716005902342.png)

¡Comparte tu recorrido con LifeUp con la comunidad!

Ahora solo necesitas mantener pulsada la tarjeta de estadísticas que quieras compartir para crear una tarjeta para compartir y enviarla a otras apps con un toque.

## 🖥️Escritorio

### ✨Conexión automática

![image-20230716020204259](_media/192/image-20230716020204259.png)

![image-20230716020210438](_media/192/image-20230716020210438.png)


Según el feedback de los usuarios, rellenar la IP es un factor importante que dificulta el uso de la versión de escritorio.

Esta actualización trae la función de detectar automáticamente la IP del servidor LifeUp Cloud.

<br/>

Requisito previo para usar esta función:

- Descargar v1.3.0 de LifeUp Cloud (puedes obtenerla de las actualizaciones de Google Play o de nuestras páginas de GitHub Releases).

Puedes detectar automáticamente la dirección IP correspondiente en la versión de escritorio, sin necesidad de rellenarla manualmente.

> Tras las pruebas, esta función está verificada principalmente en Windows.
>
> En macOS puede que aún no admita detección automática.

### 🚀**Exportar Reflexiones a markdown**

![image-20230716020241251](_media/192/image-20230716020241251.png)

![image-20230716020226764](_media/192/image-20230716020226764.png)

La versión de escritorio ahora admite exportar Reflexiones en formato markdown.

Admite agrupar y exportar de múltiples formas, y las Reflexiones incluirán adjuntos de imagen completos.

Con el formato markdown, puedes usar fácilmente **herramientas de terceros** para renderizar y convertir de nuevo a pdf, word y otros formatos.

------

### **✏️Añadir Tarea**

![image-20230716020407513](_media/192/image-20230716020407513.png)

Con la ayuda de las capacidades de la API desarrolladas anteriormente, la versión de escritorio ahora admite crear Tareas simples.

La configuración actual no cubre todas las opciones de la App, pero es suficiente para crear Tareas simples.

Las versiones posteriores seguirán ampliando las opciones para crear Tareas y admitir editar Tareas, etc.

------

### 🖥️**Paquete de instalación para macOS**

A partir de la versión 1.1.0, también empezaremos a publicar paquetes de instalación para macOS.

Tras una prueba sencilla, las funciones de la versión para macOS son básicamente normales.

Para más detalles, consulta también [🖥LifeUp Desktop (lifeupapp.fun)](https://docs.lifeupapp.fun/en/#/guide/api_desktop)
