## ✨Multiplataforma: Escritorio

![](_media/191/04.png)

![](_media/191/05.png)

Durante este periodo también probamos algo nuevo, y con la nueva actualización de la API, hicimos posible consultar diversos datos detallados de listas.

Hemos desarrollado un **software de escritorio LAN totalmente open source (https://github.com/Ayagikei/LifeUp-Desktop)** que puede conectarse a tu teléfono y mostrar diversos datos de listas, y admite algunas operaciones simples: comprar productos, completar Tareas, exportar imágenes de Reflexiones y verlas con el visor de imágenes del sistema.

El software admite teóricamente Windows, Linux y macOS.



⚠ Ten en cuenta que el escritorio sigue en una fase temprana de desarrollo.

Seguiremos manteniéndolo y añadiendo más funciones, como añadir Tareas desde el escritorio, adaptar la interfaz para la interacción, exportar Reflexiones en formato markdown, etc.

### 📝Cómo usar

Para más detalles, consulta la sección «Barra lateral → Ajustes → Labs → LifeUp Cloud».

También revisa nuestro documento: [LifeUp Desktop🖥 (lifeupapp.fun)](https://docs.lifeupapp.fun/en/#/guide/api_desktop).





## ✏️API: Consulta de datos completos de listas y más APIs

![](_media/191/06.png)

**Interfaz de datos**

Como base de datos para el cliente de escritorio, proporcionamos en esta versión una interfaz completa de consulta de datos.

Si eres desarrollador Android, puedes usar nuestro **LifeUp SDK** para consultar diversos datos en la App LifeUp.

Si eres cualquier otro tipo de desarrollador, puedes usar el protocolo HTTP para llamar a la API de «LifeUp Cloud». Esta también es la práctica en el cliente de escritorio.

Si no sabes de desarrollo, no te preocupes:

1. Primero, ahora es la mejor oportunidad para aprender.

2. Segundo, las APIs de datos anteriores están abiertas, lo que significa que los desarrolladores de la comunidad pueden usar estos datos para desarrollo secundario.

Por ejemplo, pueden diseñar páginas de listas de Tareas, páginas de Tienda y realizar desarrollo secundario más complejo (como funciones de descuento, compraventa de nabos).

Los resultados del desarrollo secundario también pueden beneficiar a todos los usuarios.



Las interfaces específicas se añadirán más adelante a la documentación de la API.

**Otras mejoras de interfaces API**

Adiciones

- Depósito y retiro en cajero automático
- Configurar «Deshabilitar compra» para Objetos
- Configurar «Color de etiqueta» para Tareas
- Configurar saldo del cajero automático directamente
- Consulta simple de detalles de Objeto especificado
- Añadir un tercer botón y opción de operación a la interfaz «confirm_dialog»

Cambios de comportamiento

- API popup confirm_dialog: si no se proporciona el texto u operación de algunos botones, el botón no se mostrará.

  Esto ofrece mayor flexibilidad en el control de popups; por ejemplo, puedes configurar un popup solo de texto sin botones para mostrar texto y mensajes motivacionales.

- API de penalización: en versiones anteriores, se podían deducir como máximo 100 Objetos; ahora el límite se ha ampliado a 9 dígitos.

### 📝 Uso

Consulta nuestra documentación de la API y el repositorio de GitHub:

[LifeUp Cloud☁️ (lifeupapp.fun)](https://docs.lifeupapp.fun/en/#/guide/api_cloud)

https://github.com/Ayagikei/LifeUp-SDK

## 🚀Otros: Optimización de rendimiento

Mediante feedback de usuarios y recopilación de datos en línea, descubrimos que la eficiencia de algunas consultas de datos en la App LifeUp se reduce significativamente con una gran cantidad de datos.

Para una aplicación de lista de tareas, la estabilidad y la durabilidad a largo plazo son cruciales.

Por ello, en esta versión hemos realizado una serie de optimizaciones para escenarios con muchos datos. Estas optimizaciones pueden mejorar significativamente la velocidad de carga de la mayoría de páginas de listas (especialmente la lista de tareas pendientes).

Seguiremos optimizando estos escenarios.

**♻️Optimizaciones**

1. Mejorar velocidad de consulta, procesamiento y rendimiento al manejar grandes cantidades de datos.
2. Corregir márgenes incorrectos para iconos adaptativos.
3. Optimizar el efecto de visualización de los registros del temporizador Pomodoro.
4. Mejorar la interacción al restaurar un respaldo.
5. Añadir visualización de interfaz para obtener la licencia mediante Google Play (para la versión de prueba gratuita de GitHub).
6. Mostrar aviso para deshabilitar la importación con un clic si el archivo de respaldo seleccionado no es de LifeUp al importar directamente desde el sistema de archivos.
7. Cerrar automáticamente el método de entrada al buscar productos en el popup de selección de productos.
8. Cambios de comportamiento de la API, incluyendo:
   - API popup Confirm_dialog. Si no se proporciona texto u operación de ciertos botones, el botón no se mostrará. Esto ofrece mayor flexibilidad en el control de popups; por ejemplo, puedes configurar un popup solo de texto sin botones para mostrar texto y mensajes motivacionales.
   - API de penalización. En versiones anteriores solo podía deducir hasta 100 Objetos; ahora el límite se ha ampliado a 9 dígitos.

**🐛Correcciones de errores**

1. Corregido el problema de que la página del temporizador Pomodoro mostraba «cargando» al final en ciertas circunstancias.
2. Corregidos cierres inesperados causados por ciertas bibliotecas de terceros.
3. Corregido el problema de que la App se cerraba al colocar el reloj Pomodoro en la barra de navegación inferior debido a un popup de aviso.
4. Corregida la visualización anormal de valores de Atributo al explorar perfiles de otros usuarios.
5. Corregido el problema de que los eventos y notificaciones de la API por reducción de Nivel de Atributo no se enviaban correctamente.
6. Corregidos algunos problemas de interacción con páginas de edición por pulsación larga.
7. Corregidos algunos márgenes anómalos en las páginas de gestión de imágenes y Síntesis.
8. Corregidas algunas ventanas popup que no eran desplazables, provocando uso anormal en modo horizontal.
