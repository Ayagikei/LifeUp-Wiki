# Clon de Wordle

Creado con HTML, CSS y JavaScript

Para jugar, [haz clic aquí](https://thejasnu.github.io/wordle-clone/)

-   Se usó CSS Grid para el teclado y las casillas de letras
-   Se usaron transiciones y animaciones para los efectos de sacudida y celebración
-   La lista de palabras proviene del sitio web oficial de The New York Times
