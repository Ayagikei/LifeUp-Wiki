## ✨Multiplataforma: Desktop

![](_media/191/04.png)

![](_media/191/05.png)

Neste período, também experimentamos algo novo e, com a nova atualização da API, tornamos possível consultar diversos dados detalhados de listas.

Desenvolvemos um **software desktop LAN totalmente open source (https://github.com/Ayagikei/LifeUp-Desktop)** que pode se conectar ao seu celular, exibir diversos dados de listas e suporta algumas operações simples: comprar produtos, concluir Tarefas, exportar imagens de Reflexões e visualizá-las no navegador de imagens do sistema.

O software suporta teoricamente Windows, Linux e macOS.



⚠ Observe que o desktop ainda está em estágio inicial de desenvolvimento.

Continuaremos mantendo e adicionando mais funções, como adicionar Tarefas pelo desktop, adaptar a interface para interação, exportar Reflexões em formato markdown, etc.

### 📝Como usar

Para detalhes, consulte a seção "Barra lateral → Configurações → Labs → LifeUp Cloud".

Consulte também nossa documentação: [LifeUp Desktop🖥 (lifeupapp.fun)](https://docs.lifeupapp.fun/en/#/guide/api_desktop).





## ✏️API: consulta de dados completos de listas e mais APIs

![](_media/191/06.png)

**Interface de dados**

Como base de dados para o cliente desktop, fornecemos uma interface completa de consulta de dados nesta versão.

Se você é desenvolvedor Android, pode usar nosso **LifeUp SDK** para consultar diversos dados no App LifeUp.

Se você é de outro tipo de desenvolvedor, pode usar o protocolo HTTP para chamar a API "LifeUp Cloud". Essa também é a prática no cliente desktop.

Se não sabe sobre desenvolvimento, não se preocupe:

1. Primeiro, agora é a melhor oportunidade de aprender.

2. Segundo, as APIs de dados acima estão abertas, o que significa que desenvolvedores da comunidade podem usá-las para desenvolvimento secundário.

Por exemplo, podem projetar páginas de lista de Tarefas, páginas da Loja e realizar desenvolvimento secundário mais complexo (como descontos, funções de compra e venda de nabos).

Os resultados do desenvolvimento secundário também podem beneficiar todos os usuários.



Interfaces específicas serão adicionadas à documentação da API posteriormente.

**Outras melhorias de interface da API**

Adições

- Depósito e saque no caixa eletrônico
- Definir "Desabilitar compra" para Itens
- Definir "Cor da tag" para Tarefas
- Definir saldo do caixa eletrônico diretamente
- Consulta simples de detalhes de item especificado
- Adicionar terceiro botão e opção de operação à interface "confirm_dialog"

Mudanças de comportamento

- API pop-up confirm_dialog: se o texto ou operação de alguns botões não for fornecido, o botão não será exibido.

  Isso oferece maior flexibilidade no controle de pop-ups; por exemplo, você pode definir um pop-up apenas com texto, sem botões, para exibir texto e mensagens motivacionais.

- API de penalidade: em versões anteriores, no máximo 100 Itens podiam ser deduzidos; agora o limite foi expandido para 9 dígitos.

### 📝 Uso

Consulte nossa documentação da API e repositório GitHub:

[LifeUp Cloud☁️ (lifeupapp.fun)](https://docs.lifeupapp.fun/en/#/guide/api_cloud)

https://github.com/Ayagikei/LifeUp-SDK

## 🍅Pomodoro: tempo automático de trabalho e descanso

![screely-1676558398757](_media/191/07.png)

Esta versão também introduz o início automático do relógio Pomodoro.

Certifique-se de que seu celular tenha sido **configurado para compatibilidade** para evitar que o sistema interrompa o funcionamento do Pomodoro.

Observe que, ao ativar "Início automático do descanso", a função original de contagem regressiva adicional será desabilitada.

### 📝 Uso

Acesse Pomodoro → página de configurações no canto superior direito.

## 🚀Outros: otimização de desempenho

Por meio de feedback de usuários e coleta de dados online, descobrimos que a eficiência de algumas consultas de dados no App LifeUp cai significativamente quando há grande volume de dados.

Para um app de lista de tarefas, estabilidade e uso de longo prazo são cruciais.

Portanto, nesta versão, fizemos uma série de otimizações para cenários com grande volume de dados. Essas otimizações podem melhorar significativamente a velocidade de carregamento da maioria das páginas de listas (especialmente a página de lista de tarefas).

Continuaremos otimizando esses cenários.
