<h1 align="center" padding="100">v1.98.0 API 2.0 e atualização do cliente Desktop</h1>


## Introdução
Esta é a primeira versão de 2025, com as seguintes atualizações principais:

- Suporte a ícones Emoji: agora você pode usar Emojis diretamente como ícones de Itens, Conquistas e mais.

- Segunda onda de atualizações da API: as interfaces da API agora suportam modificação de Tarefas, edição de efeitos de Itens, condições de desbloqueio de Conquistas, Síntese e quase todas as funcionalidades centrais.

- LifeUp Cloud e otimização do cliente Desktop: experiência aprimorada de detecção automática de conexão; o cliente desktop adiciona o recurso "Novas Reflexões" e suporta importação/exportação de dados de backup.

## I. Ícones Emoji

![image-20250106213004522](./_media/198/image-20250106213004522.png)

### 📕Como usar?

- Nesta versão, ao selecionar ícones para Itens, Conquistas, etc., agora você pode escolher diretamente expressões emoji como ícones.

## II. Segunda onda de atualizações da API
![image-20250106212817689](./_media/198/image-20250106212817689.png)

Desde que a funcionalidade da API foi aberta no v1.90.0, ficamos felizes em ver muitos usuários explorando ativamente e criando conteúdo rico com base na API. Muitos usuários começaram do zero aprendendo conhecimentos relacionados a URL e aplicaram a API com sucesso para criar widgets de desktop, clientes desktop DIY e até integração com aplicativos web — impressionante.

Porém, devido a estruturas de dados complexas e volume substancial de trabalho de design e desenvolvimento, o primeiro lote de APIs carecia de algumas funcionalidades centrais, como editar Tarefas, editar Itens, criar Conquistas com condições de desbloqueio e criar Itens com efeitos de uso. A conclusão desses recursos continuou até esta versão.

O design, desenvolvimento, testes e atualizações da nuvem, clientes desktop e documentação da API trouxeram carga de trabalho exponencialmente crescente, fazendo com que o branch de desenvolvimento iniciado há vários meses só concluísse desenvolvimento e testes agora.

**Mas nossos esforços valeram a pena! Hoje, a API cobre quase todas as funcionalidades centrais do LifeUp. Ao abrir a API, esperamos que o LifeUp seja mais do que apenas um aplicativo — uma plataforma aberta onde os usuários podem desenvolver, estender e personalizar livremente seus próprios sistemas de gamificação.**

### 📕Como usar?

- Para métodos de uso da API, consulte nossa biblioteca de documentação → Diretório → seção Interface aberta.
- Definições de novas interfaces da API foram adicionadas à documentação.

## III. Cliente Desktop: recurso de arquivo e Reflexões

### Arquivo

![image-20250106212442295](./_media/198/image-20250106212442295.png)

Agora você pode exportar ou importar arquivos de backup diretamente no cliente desktop.

Isso simplificará o processo de transferir dados para outros dispositivos e recuperação.

### Publicar novas Reflexões

![image-20240927225309975](./_media/198/image-20240927225309975.png)

Agora suporta publicar novas Reflexões pelo cliente desktop, com suporte completo para adicionar imagens e definir recursos de horário.

⚠️Nota: Edição de Reflexões ainda não é suportada.

### Outras atualizações

- Otimizadas mensagens e explicações de erro relacionadas à conexão: indicando claramente se é problema de rede ou porque o backend do LifeUp não está em execução
- Suporte à visualização de detalhes de Tarefas
- Suporte à validação de segurança do API Token (opcional, requer LifeUp Cloud 2.0.0)
- A lógica de compra agora usa a nova "API de compra de item" em vez da anterior "API de ajuste de quantidade de item" + "API de ajuste de quantidade de moedas". Assim, agora trata corretamente a lógica de limite de compra, mantendo consistência com o App.

Esta atualização também serve para demonstrar as capacidades da API pelo cliente desktop, pois todos os recursos do cliente desktop são implementados por meio da API.

## IV. Otimização do LifeUp Cloud

> LifeUp Cloud é uma ferramenta que expõe a API como interfaces HTTP e serve como ponte para conexão do cliente desktop.

![image-20250106212715220](./_media/198/image-20250106212715220.png)

![image-20250106212725277](./_media/198/image-20250106212725277.png)

Fizemos numerosas otimizações com base no feedback sobre o LifeUp Cloud:

- Adicionada exibição de status para detectar rapidamente por que o cliente desktop não conecta
- Adicionadas configurações avançadas
  - Permitir acesso cross-origin: útil para acessar interfaces HTTP do LifeUp Cloud com tecnologias web
  - Permitir portas de serviço personalizadas
  - Permitir definir tokens de acesso: medida opcional de validação de segurança
- Otimizados valores de retorno de erro e especificações das interfaces do LifeUp Cloud
- Otimizada lógica de descoberta de serviço e interruptor de serviço HTTP; a detecção automática do cliente desktop deve funcionar melhor agora

## V. Prévia

Como esta atualização traz relativamente poucos recursos fora da API, aqui está uma prévia do conteúdo das próximas versões, incluindo recursos em desenvolvimento:

- **Recurso principal:** Conquistas repetíveis
- **Recurso médio:** Otimização de legibilidade de texto para fundos personalizados
  - Originalmente parecia uma mudança pequena, mas acabou sendo bem complexa
- **Recurso menor:** Adicionar ações concluir e lembrar depois às notificações
  - Originalmente planejado suporte a notificações persistentes, mas abandonado pois versões mais recentes do Android não suportam mais persistência real
