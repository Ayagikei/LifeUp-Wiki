# Termos e política de privacidade da App *Calendar Account Delete Helper*

!> [Play Store](https://play.google.com/store/apps/details?id=fun.lifeupapp.calmanager)

## 1. Informações pessoais

Não coletamos informações pessoais, nem mesmo dados de desempenho relacionados ao app.

## 2. Permissões

### Calendário

O aplicativo solicita apenas permissões de leitura e gravação do calendário, usadas para obter a
lista de contas de calendário e realizar operações de exclusão.

### Sem permissões de rede

Todas as operações são realizadas localmente. O app não solicita permissões de rede e, portanto, os dados não são
transmitidos para fora do aplicativo.

## 3. Acordo

Ao usar este App, você concorda com os termos desta política de privacidade.

Você concorda que é responsável pelos seus próprios dados.
