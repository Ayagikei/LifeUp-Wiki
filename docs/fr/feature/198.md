<h1 align="center" padding="100">v1.98.0 API 2.0 et mise à jour du client de bureau</h1>


## Introduction
Première version de 2025, avec les mises à jour majeures suivantes :

- Prise en charge des icônes Emoji : vous pouvez désormais utiliser directement des Emoji comme icônes pour les Objets, Succès, etc.

- Deuxième vague de mises à jour API : les interfaces API prennent en charge la modification des Tâches, l'édition des effets d'Objets, les conditions de déblocage des Succès, la Synthèse et presque toutes les fonctionnalités principales.

- Optimisation de LifeUp Cloud et du client de bureau : amélioration de la détection automatique de connexion ; le client de bureau ajoute la fonction « Nouvelles Émotions » et prend en charge l'import/export des données de sauvegarde.

## I. Icônes Emoji

![image-20250106213004522](./_media/198/image-20250106213004522.png)

### 📕Comment utiliser ?

- Dans cette version, lors de la sélection d'icônes pour les Objets, Succès, etc., vous pouvez désormais choisir directement des expressions Emoji comme icônes.

## II. Deuxième vague de mises à jour API
![image-20250106212817689](./_media/198/image-20250106212817689.png)

Depuis l'ouverture des fonctionnalités API en v1.90.0, nous sommes ravis de voir de nombreux utilisateurs explorer activement l'API et créer du contenu riche. Beaucoup ont appris les bases des URL depuis zéro et ont réussi à créer des widgets de bureau, des clients de bureau DIY, voire une intégration d'applications web — c'est impressionnant.

Cependant, en raison de structures de données complexes et d'une charge de conception et de développement importante, le premier lot d'API manquait de certaines fonctionnalités principales, comme l'édition des Tâches, l'édition des Objets, la création de Succès avec conditions de déblocage et la création d'Objets avec effets d'utilisation. L'achèvement de ces fonctionnalités s'est poursuivi jusqu'à cette version.

La conception, le développement, les tests et les mises à jour du cloud, des clients de bureau et de la documentation API ont entraîné une charge de travail exponentielle, si bien que la branche de développement lancée il y a plusieurs mois n'a pu terminer développement et tests qu'aujourd'hui.

**Mais nos efforts ont porté leurs fruits ! Aujourd'hui, l'API couvre presque toutes les fonctionnalités principales de LifeUp. En ouvrant l'API, nous espérons faire de LifeUp bien plus qu'une App : une plateforme ouverte où les utilisateurs peuvent librement développer, étendre et personnaliser leurs propres systèmes de gamification.**

### 📕Comment utiliser ?

- Pour les méthodes d'utilisation de l'API, consultez notre bibliothèque de documentation → Répertoire → section Interface ouverte.
- Les définitions des nouvelles interfaces API ont été ajoutées à la documentation.

## III. Client de bureau : archive et Émotions

### Archive

![image-20250106212442295](./_media/198/image-20250106212442295.png)

Vous pouvez désormais exporter ou importer directement des fichiers de sauvegarde sur le client de bureau.

Cela simplifiera le transfert de données vers d'autres appareils et la récupération.

### Publier de nouvelles Émotions

![image-20240927225309975](./_media/198/image-20240927225309975.png)

Prise en charge de la publication de nouvelles Émotions depuis le client de bureau, avec ajout d'images et réglage de l'heure.

⚠️Note : l'édition des Émotions n'est pas encore prise en charge.

### Autres mises à jour

- Messages et explications d'erreur liés à la connexion optimisés : indication claire s'il s'agit d'un problème réseau ou de LifeUp backend non démarré
- Prise en charge de l'affichage des détails des Tâches
- Prise en charge de la validation de sécurité du jeton API (optionnelle, nécessite LifeUp Cloud 2.0.0)
- La logique d'achat utilise désormais la nouvelle API « purchase item » au lieu des anciennes API « adjust item quantity » + « adjust coin amount ». Elle gère correctement la logique de limite d'achat, en cohérence avec l'App.

Cette mise à jour sert aussi à démontrer les capacités de l'API via le client de bureau, car toutes les fonctionnalités du client de bureau sont implémentées via l'API.

## IV. Optimisation de LifeUp Cloud

> LifeUp Cloud est un outil qui expose l'API en interfaces HTTP et sert de pont pour la connexion du client de bureau.

![image-20250106212715220](./_media/198/image-20250106212715220.png)

![image-20250106212725277](./_media/198/image-20250106212725277.png)

Nous avons apporté de nombreuses optimisations suite aux retours sur LifeUp Cloud :

- Affichage de l'état pour détecter rapidement pourquoi le client de bureau ne peut pas se connecter
- Paramètres avancés ajoutés
  - Autoriser l'accès cross-origin : utile pour accéder aux interfaces HTTP de LifeUp Cloud avec des technologies web
  - Autoriser des ports de service personnalisés
  - Autoriser la définition de jetons d'accès : mesure de validation de sécurité optionnelle
- Valeurs d'erreur et spécifications optimisées pour les interfaces de LifeUp Cloud
- Logique de découverte de service et de bascule du service HTTP optimisée ; la détection automatique du client de bureau devrait mieux fonctionner

## V. Aperçu

Comme cette mise à jour apporte relativement peu de fonctionnalités hors API, voici un aperçu du contenu des prochaines versions, y compris les fonctionnalités en cours de développement :

- **Fonctionnalité majeure :** Succès répétables
- **Fonctionnalité moyenne :** Optimisation de la lisibilité du texte pour les arrière-plans personnalisés
  - Pensée initialement comme un petit changement, mais s'est avérée assez complexe
- **Fonctionnalité mineure :** Actions « terminer » et « rappeler plus tard » dans les notifications
  - Notifications persistantes initialement prévues, mais abandonnées car les versions récentes d'Android ne les prennent plus en charge
