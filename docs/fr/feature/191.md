## ✨Multiplateforme : bureau

![](_media/191/04.png)

![](_media/191/05.png)

Pendant cette période, nous avons aussi essayé quelque chose de nouveau ; avec la nouvelle mise à jour API, nous avons rendu possible la requête de diverses données détaillées de liste.

Nous avons développé un **logiciel de bureau LAN entièrement open source (https://github.com/Ayagikei/LifeUp-Desktop)** qui peut se connecter à votre téléphone, afficher diverses données de liste et prend en charge quelques opérations simples : acheter des produits, terminer des Tâches, exporter des images de réflexion et les consulter avec le navigateur d'images système.

Le logiciel prend en charge théoriquement Windows, Linux et macOS.



⚠ Notez que le bureau en est encore aux premiers stades de développement.

Nous continuerons à le maintenir et à ajouter des fonctions, comme l'ajout de Tâches via le bureau, l'adaptation de l'interface pour l'interaction, l'export des réflexions au format markdown, etc.

### 📝Comment utiliser

Pour les détails, consultez la section « Menu latéral → Paramètres → Labs → LifeUp Cloud ».

Consultez aussi notre document : [LifeUp Desktop🖥 (lifeupapp.fun)](https://docs.lifeupapp.fun/en/#/guide/api_desktop).





## ✏️API : requête de données de liste complètes et plus d'API

![](_media/191/06.png)

**Interface de données**

Comme fondation de source de données pour le client de bureau, nous fournissons dans cette version une interface de requête de données complète.

Si vous êtes développeur Android, vous pouvez utiliser notre **LifeUp SDK** pour interroger diverses données dans l'App LifeUp.

Si vous êtes un autre type de développeur, vous pouvez utiliser le protocole HTTP pour appeler l'API « LifeUp Cloud ». C'est aussi la pratique sur le client de bureau.

Si vous ne connaissez pas le développement, pas d'inquiétude :

1. D'abord, c'est la meilleure occasion d'apprendre.

2. Ensuite, les API de données ci-dessus sont ouvertes, ce qui signifie que les développeurs de la communauté peuvent les utiliser pour du développement secondaire.

Par exemple, ils peuvent concevoir des pages de liste de Tâches, des pages Boutique, et réaliser un développement secondaire plus complexe (comme remises, achat/vente de navets).

Les résultats du développement secondaire peuvent aussi profiter à tous les utilisateurs.



Les interfaces spécifiques seront ajoutées à la documentation API ultérieurement.

**Autres améliorations d'interface API**

Ajouts

- Dépôt et retrait au distributeur
- Définir « Désactiver l'achat » pour les Objets
- Définir « Couleur de tag » pour les Tâches
- Définir directement le solde du distributeur
- Requête simple des détails d'un Objet spécifié
- Ajouter un troisième bouton et une option d'opération à l'interface « confirm_dialog »

Changements de comportement

- API popup confirm_dialog : si le texte ou l'opération de certains boutons n'est pas fourni, le bouton ne s'affiche pas.

  Cela offre plus de flexibilité dans le contrôle des popups, par exemple une popup texte seule sans boutons pour afficher du texte et des messages motivants.

- API pénalité : dans les versions passées, un maximum de 100 Objets pouvaient être déduits ; la limite est maintenant étendue à 9 chiffres.

![screely-1676558398757](_media/191/07.png)

Cette version introduit aussi le démarrage automatique de l'horloge Pomodoro.

## 🚀Autres : optimisation des performances

Grâce aux retours utilisateurs et à la collecte de données en ligne, nous avons constaté que l'efficacité de certaines requêtes de données dans l'App LifeUp diminue significativement avec un volume important de données.

Pour une app de liste de tâches, stabilité et durabilité sont cruciales.

Dans cette version, nous avons donc apporté une série d'optimisations pour les scénarios à grand volume de données. Ces optimisations améliorent nettement la vitesse de chargement de la plupart des pages de liste (surtout la page de liste de Tâches).

Nous continuerons à optimiser pour ces scénarios.

## 4e anniversaire

Nous espérons que vous apprécierez cette mise à jour !

Cela fait 4 ans que nous développons LifeUp, et nous continuerons à apporter davantage de mises à jour et d'optimisations.

Mais nous réalisons aussi qu'un achat unique n'est pas très favorable à la maintenance à long terme d'une App. Rassurez-vous, nous restons aussi partisans de l'achat unique.

Nous aimerions avoir l'occasion de travailler à temps plein sur LifeUp. Mais LifeUp reste une App de niche. Par manque de temps, dans les versions récentes, nous avons conçu diverses API pour permettre à la communauté de participer à la construction de davantage de fonctions.



Si vous pensez que LifeUp vous aide et si vous voulez offrir un café aux développeurs sur la page about, ou recommander LifeUp à vos amis et communautés, tout cela contribuera à notre maintenance à long terme et nous rapprochera du développement à temps plein.

Merci encore d'utiliser LifeUp !
