# Clone Wordle

Réalisé avec HTML, CSS et JavaScript

Pour jouer, [cliquez ici](https://thejasnu.github.io/wordle-clone/)

-   Grille CSS pour le clavier et les tuiles de lettres
-   Transitions et animations pour les effets de secousse et de célébration
-   La liste de mots provient du site officiel du New York Times
