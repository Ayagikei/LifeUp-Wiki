**v1.105.2 (2026/08/24)**

**🐛 버그 수정**

1. **스마트 목록을 선택했을 때 작업 선택기에 빈 목록이 표시되던 문제를 수정했습니다.**

**v1.105.1 (2026/08/19)**

**✨ 기능**

1. **장면별로 커스텀 효과음을 끌 수 있습니다**: 한 가지 알림만 음소거해도 다른 알림에는 영향을 주지 않으며, 미리듣기는 계속 재생되어 소리를 확인할 수 있습니다.

**♻️ 최적화**

1. **Google Play 서비스를 사용할 수 없을 때 백업 안내를 더 명확하게 개선**: Google Drive를 사용할 수 없으면 App이 이유를 설명하고 로컬 파일, Dropbox, WebDAV를 제안합니다.

**🐛 버그 수정**

1. **캘린더 완료 페이지에서 실행 취소를 탭해도 아무 동작도 하지 않던 문제를 수정했습니다.**
2. **아이템을 편집할 때 구매/사용 제한이 복원되지 않거나(빈 값으로 저장되는) 문제를 수정했습니다.**

**v1.105.0 (2026/08/04)**

**ℹ️ 중요 안내**

1. **Android 6.0이 이제 최소 지원 버전입니다**: 최신 Android 버전의 기능 및 동작 요구 사항을 선제적으로 지원하기 위해 최소 지원 버전이 Android 5.0에서 Android 6.0으로 상향되었습니다. Android 5.x 사용자는 이 버전을 설치하거나 업그레이드할 수 없습니다.

**✨ 기능**

1. **포모도로 제어 URL Scheme API 추가**: 상태 조회, 작업 선택, 포모도로/카운트업 세션 시작·일시 정지·건너뛰기·포기·완료가 가능합니다.
2. **커스텀 작업 정렬 메커니즘 개선**: 복사, 완료, 실행 취소 및 기타 예외 상황에서도 커스텀 순서가 안정적으로 유지되도록 새 정렬 메커니즘을 도입했습니다.

**♻️ 최적화**

1. **Android 예측 뒤로 가기 지원 추가**: 작업, 상점, 합성, 업적 편집기에서 시스템 예측 뒤로 가기 제스처를 지원합니다.
2. **Facebook 로그인 초기화 개선**: 로그인 요청 시 SDK를 초기화하고 오류 상태 처리를 개선했습니다.

**🐛 버그 수정**

1. **편집 URL Scheme 요청이 기존 필드를 의도치 않게 덮어쓰던 문제 수정**: 생략된 필드는 이전 값을 유지하며, 잘못된 보상 또는 관계 매개변수가 더 이상 기존 데이터를 지우지 않습니다.
2. **특정 예외 상황에서 양의 타이머 알림 제목이 선택한 작업을 따르지 않던 문제를 수정했습니다.**
3. **첫 번째 16진수 색상 값을 붙여넣은 뒤 RGB 미리보기가 갱신되지 않던 문제를 수정했습니다.**
4. **합성 및 업적 상세 페이지 선택 도구 모음에 그림자가 없던 문제를 수정했습니다.**

**v1.104.6 (2026/07/19, Google Play)**

**🐛 버그 수정**

1. **App 또는 타이머 서비스가 예기치 않게 중단된 뒤 포모도로 세션이 올바르게 복원되지 않던 문제 수정**: 유효한 세션은 이제 올바르게 복원되며, 잘못된 오래된 상태는 정리됩니다.
2. **시스템 시간대 변경 후 동일한 안내가 반복 표시되던 문제 수정**: 조정을 확인한 뒤 작업 시간이 올바르게 업데이트되며 같은 안내가 다시 표시되지 않습니다.

**v1.104.5 (2026/07/17)**

**🐛 버그 수정**

1. **v1.104.4 릴리스 빌드에서 포모도로 페이지를 열면 App이 충돌할 수 있던 문제를 수정했습니다.**

**v1.104.4 (2026/07/17)**

**✨ 기능**

1. **아이템이 속성 경험치 범위 기반 구매/사용 제한을 지원**: 최소·최대 경험치 조건을 설정해 아이템 구매, 사용 또는 둘 다를 제어할 수 있습니다.
2. **하루에 작업을 총 N회 완료하는 새 업적 조건**: 기존 서로 다른 작업 조건과 달리, 같은 작업을 반복 완료한 경우도 포함해 해당 날의 모든 유효한 작업 완료를 집계합니다.

**♻️ 최적화**

1. **포모도로 정산 및 복구 흐름 재구축**: 타이머 상태, 집중 기록, 보상 정산이 이제 통합된 프로세스를 따릅니다. App 프로세스가 종료된 경우에도 복구가 더 안정적이며, 집중 시간 누락 같은 예외 상황이 줄어듭니다. 예상치 못한 동작 변화가 있으면 lifeup@ulives.io로 문의해 주세요.
2. **합성 레시피 수량 편집이 더 수월해짐**: 기존 재료나 결과를 탭해 같은 아이템을 다시 선택하지 않고 수량을 직접 편집할 수 있습니다. 필요하면 아이템을 다시 선택할 수도 있습니다.
3. **홈 화면에서 포모도로를 가로 모드로 바로 열 수 있음**: 가로 레이아웃에서 타이머를 더 편하게 보고 조작할 수 있습니다.

**v1.104.3 (2026/07/09)**

**✨ 기능**

1. **환영 화면에 새 "빠른 설정" 가이드**: 소개 카드 뒤 새 페이지(5, 6)에서 알림 권한, 알림 방식, UI 스타일(Material 2/3), 다중 창 표시를 온보딩 중 아코디언 스타일 카드로 바로 설정할 수 있습니다. 모든 옵션은 나중에 설정에서 조정할 수 있습니다.

**♻️ 최적화**

1. **환영 페이지 소개 문구 업데이트**: 1~4페이지를 다시 작성해 App의 핵심 가치를 더 잘 전달합니다: 커스텀 작업 → 스탯 성장 → 보상 시스템 → 세계와 연결.
2. **합성 대화상자를 하단 시트로 재설계**: 재료와 결과가 세로 그리드로 표시되어 레이아웃이 더 깔끔하고 직관적입니다.
3. **할 일 목록 전환, 정렬 순서 변경, 그룹화 설정 토글 시 데이터 로딩 속도 개선**.

**🐛 버그 수정**

1. **특정 시스템 업적에서 "업적 해금" 알림이 중복 표시되던 문제 수정**.
2. **"하루에 서로 다른 N개 작업 완료" 업적 집계 부정확 문제 수정**: 무한 작업이 더 이상 제외되지 않으며, 같은 날 같은 작업을 여러 번 완료해도 1회로 집계됩니다.
3. **작업 목록의 추가 버튼(+)이 가끔 올바른 위치에서 벗어나던 문제 수정**.
4. **"목록별 그룹화"가 꺼져 있을 때 스마트 목록이 보관된 작업을 필터링하지 않던 문제 수정**.

**v1.104.2 (2026/07/03)**

**✨ 기능**

1. **통계 페이지의 "사용 일수"를 "함께한 날"로 변경**: 카드를 탭해 시작 날짜를 커스터마이즈하고 나만의 기념일을 정의할 수 있습니다. 관련 업적 조건 설명도 "함께한" 표현을 사용하도록 업데이트되었습니다.
2. **백업 메뉴에 "백업 및 공유" 옵션 추가**: 시스템 공유 패널을 통해 백업 파일을 다른 App으로 바로 공유할 수 있습니다.
3. **전리품 상자 효과 API v2**: 새 `loot_box/v2` 경로가 `sub_amount`를 통한 정밀 아이템 매칭, 아이템 추가/제거, 수량 및 확률 모드의 독립 제어를 지원합니다.

**♻️ 최적화**

1. **URL Scheme이 상점 아이템, 전리품 상자, 하위 작업 편집 시 정확한 이름 매칭을 우선**: 정확히 일치하는 항목이 없을 때만 유사 매칭으로 폴백하여 의도치 않은 편집을 방지합니다.
2. **사이드바 영어 "FAQ"를 "Notice"로 변경**: 중국어 버전은 이미 "公告"이며 변경 없음.
3. **버튼 리플 효과가 모든 곳에서 모서리 반경과 일치**: 둥근 컨트롤의 리플 애니메이션이 모서리 경계를 넘지 않아 App 전반에서 탭 느낌이 더 정돈되었습니다.

**🐛 버그 수정**

1. **포모도로 기록 추가 또는 편집 후 포모도로 페이지의 토마토 수가 자동 갱신되지 않던 문제 수정**.
2. **포모도로 기록 추가 후 획득 토마토 토스트가 가끔 표시되지 않던 문제 수정**.
3. **수동 추가 포모도로 기록이 기록에서 선택한 작업이 아닌 현재 선택된 작업 기준으로 토마토를 계산하던 문제 수정**: 이제 기록에서 실제 선택한 작업의 작업별 집중 시간을 사용합니다. 작업마다 집중 시간을 다르게 설정했다면 수동 기록 토마토가 더 정확해집니다.
4. **기록에서 무한 작업의 "완료 횟수" 표시 오류 수정**: 이제 해당 날의 순번(예: "그날 N번째")으로 표시됩니다.
5. **페널티 작업 동기 부여 문구가 표시되지 않던 문제 수정** — 페널티 완료 후 표시됩니다.

**v1.104.1 (2026/06/17)**

**✨ 기능**

1. **백업 내보내기 옵션 강화**: 수동 백업 생성 시 새 하단 시트에서 미디어 파일, 계정 민감 정보(로그인 상태, WebDAV 자격 증명 등), 이모지 이미지 포함 여부를 선택할 수 있어 정제된 백업 공유가 쉬워졌습니다. 자동 백업 섹션에도 세 가지 해당 토글이 영구 추가되었습니다.
2. **포모도로 작업 선택기 개선**: 시간 제한 작업이 작업 선택기 맨 위에 현재 집중 진행률(집중 시간 / 목표 시간 / 백분율)과 함께 표시됩니다. 빠른 접근을 위해 시간 제한 작업 우선 표시를 켜거나 끌 수 있습니다.
3. **정보 페이지 재설계**: 정보 페이지를 링크, 피드백, 커뮤니티, 개발자 섹션으로 재구성하고 웹사이트, 릴리스 로그, FAQ, API 문서 항목을 추가했습니다. 간체 중국어 사용자에게 Tencent Channel 항목이, 해외 사용자에게 GitHub Issues/Discussions 커뮤니티 접근이 제공됩니다.
4. **팔로워 제거**: 팀 멤버 페이지에서 팔로워를 제거할 수 있습니다.
5. **상점 속성 선택기 강화**: 상점 경험치/효과 입력 대화상자에 속성 선택 버튼을 추가해 스킬 그룹별 빠른 필터링과 일괄 다중 선택을 지원 — 속성이 많을 때 훨씬 편리합니다.

**♻️ 최적화**

1. **포모도로 통계 시간 표시 형식 전환 지원**: 작업 상세 페이지의 포모도로 통계 영역을 탭해 "시간/분", "일/시간/분", "총 분"을 순환합니다.
2. **하위 작업 완료 상태가 더 명확**: 완료된 하위 작업에 취소선이 표시되어 완료와 미완료 구분이 더 분명합니다.
3. **포모도로 기록 정렬 수정**: 포모도로 기록이 종료 시간 내림차순으로 정렬됩니다.

**🐛 버그 수정**

1. **여러 언어의 ATM 출금 버튼 문구 수정**: 일부 로케일에서 ATM 출금 버튼 문구의 동명사 오용을 수정했습니다.
2. **로그인하지 않은 상태의 상점 아이템 공유 동작 수정**: 로그인 없이 상점 아이템을 공유할 때 비정상 동작을 해결했습니다.
3. **색상 선택기 에코 상태 수정**: 색상 선택기 대화상자에 잘못된 선택 상태가 표시되던 문제를 수정했습니다.

**v1.104.0 (2026/05/23)**

**✨ 기능**

1. **카운트 작업이 비례 실시간 보상 정산을 지원**: 주당 몇 번 완료하는 습관처럼 주기 내 유연한 시점에 여러 번 진행하는 작업에 유용합니다. 카운트 진행이 변경되면 LifeUp이 최종 완료를 기다리지 않고 현재 진행률에 따라 경험치, 코인, 아이템 보상을 지급하거나 롤백할 수 있습니다.
2. **작업 상세 기록 도구 강화**: 기록 캘린더에서 날짜를 선택하면 해당 날짜의 횟수가 표시되며, 기록 추가·편집·일괄 생성이 가능합니다.
3. **감정과 아이템 연결 개선**: 아이템 상세에서 관련 감정으로 바로 이동할 수 있으며, 감정 페이지에서 상점 아이템별 필터링을 지원합니다.
4. **하위 작업 완료 시간 기록**: LifeUp이 각 하위 작업 완료 시점을 기록하여 향후 API 및 LifeUp Cloud 지원 데이터를 준비합니다.
