# LifeUp 백그라운드 실행 유지

## 왜 필요한가

일부 휴대폰 제조사는 배터리 벤치마크 점수를 높이기 위해 백그라운드 App을 공격적으로 제한합니다. 그 결과 백그라운드 실행에 의존하는 기능이 실패할 수 있습니다.

### 호환성 영향 매트릭스

| 기능 | 백그라운드 유지 필요? | 추가 권한 | 참고 |
| --- | --- | --- | --- |
| 작업 알림(시스템 알림) | ✔️ | 알림 권한 | 기본 알림 방식입니다. 알림이 지연되거나 누락되면 백그라운드 유지를 구성하고 LifeUp 알림이 켜져 있는지 확인하세요. |
| 작업 알림(캘린더 이벤트) | ✖️ | 캘린더 읽기/쓰기 권한 | `설정` → `작업` → `알림 시스템 변경`에서 이 모드로 전환할 수 있습니다. |
| 뽀모도로 종료 알림 | ✔️ | - | 유지 설정이 없으면 알림을 놓칠 수 있고, 백그라운드에서 카운트다운이 멈추거나 고정될 수 있습니다. |
| 카운트업 타이머 | ✖️ | - | - |
| App 위젯 자동 새로고침 | 보통 예(기기/OS에 따라 다름) | - | 유지 설정이 없으면 위젯이 "로딩 중"에 머물거나 "모든 작업 완료" 같은 오래된 상태를 표시할 수 있습니다. |
| 위젯 동작: 횟수 작업 완료 / 작업 상세 열기(MIUI 아님) | ✖️ | - | - |
| 위젯 동작: 횟수 작업 완료 / 작업 상세 열기(MIUI) | 경우에 따라 | MIUI 전용 백그라운드 팝업/표시 권한 필요할 수 있음 | MIUI는 백그라운드에서 위젯으로 트리거된 UI 동작을 차단할 수 있습니다. |

- 일부 시스템은 화면이 꺼지면 백그라운드 작업을 동결하거나 종료합니다.
- 위젯은 런처와 OS 변형에 따라 다르게 동작할 수 있습니다.
- 알림만 중요하다면 캘린더 알림으로 전환해 백그라운드 의존을 줄일 수 있습니다.

## 설정 방법

> [!WARNING]
> 이 설정은 배터리 사용량을 약간 늘릴 수 있습니다.

OnePlus 8T 테스트 기준 24시간 백그라운드 사용량은 약 **30 mAh**였습니다. 대부분 사용자에게는 영향이 작습니다.

LifeUp은 알림, 위젯 업데이트, 뽀모도로 타이밍 등 제한된 수동적 백그라운드 작업만 수행합니다.

---

### 일반 설정 단계

#### 일반 설정

> 모든 단계를 완료할 필요는 없습니다. 각 단계는 백그라운드 우선순위와 안정성을 개선할 수 있습니다.

**Android 시스템 설정**

1. LifeUp에서 `사이드바` → `설정` → `호환성 문제`를 연 뒤 `배터리 최적화 설정으로 이동`을 탭합니다. LifeUp을 찾아 **최적화하지 않음**으로 설정합니다.

   a. 일부 기기에서는 이 페이지로 이동해도 LifeUp이 보이지 않을 수 있습니다. 그런 경우 이 단계는 건너뛰세요.

2. 알림이 필요하면 LifeUp에 알림 권한이 부여되었는지 확인하세요.

3. (선택) 작업 설정에서 `빠른 추가 알림`을 활성화합니다.

<br/>

**제조사 백그라운드 관리(Phone Manager)**

많은 제조사가 추가 백그라운드 제한을 둡니다. Pixel/AOSP 계열이 아니면 보통 추가 구성이 필요합니다.

1. 시스템 멀티태스킹/최근 App 화면에서 LifeUp을 고정합니다.

2. 시스템 App 관리 / 배터리 관리 / Phone Manager에서 LifeUp에 백그라운드 실행 허용(제한 없음) 및 자동 시작 허용을 설정합니다.

   a. 제조사별 가이드는 [dontkillmyapp.com](https://dontkillmyapp.com/)을 참고하세요.

3. LifeUp 기능 사용 시 초절전 모드나 엄격한 방해 금지 정책 같은 공격적 모드는 피하거나, LifeUp을 관련 허용 목록에 추가하세요.

<br/>

**여전히 동작하지 않나요?**

사용자 보고와 테스트 기준, 올바르게 설정하면 LifeUp은 주류 기기에서 정상 동작합니다. 다만 시스템 업데이트로 설정 위치나 이름이 바뀔 수 있습니다.

1. 위 단계를 다시 확인하고 빠진 설정을 채웁니다.

   a. Phone Manager 제한은 여러 페이지에 흩어져 있으며 표준 App 권한 목록에 없을 수 있습니다.

   b. 선택 단계(예: 지속 알림 활성화)를 시도하고 다시 테스트합니다.

   c. 시스템 설정에서 배터리 최적화, 백그라운드 제한, 자동 시작, 팝업/백그라운드 표시 옵션을 검색합니다.

   d. 알림만 중요하면 `캘린더 알림` 모드를 시도합니다.

2. 커뮤니티에서 같은 제조사/모델 사용자에게 물어보고 OS 버전을 포함하세요.

3. 휴대폰 제조사 지원에 문의해 특정 App이 백그라운드에서 종료되지 않게 하는 방법을 확인하세요.

---

### App 위젯이 동작하지 않을 때

1. LifeUp을 먼저 열고 잠시 포그라운드에서 실행 상태를 유지합니다.
2. 위젯을 다시 추가합니다(필요하면 여러 번 시도).
3. 나중에 다시 실패하면 이 가이드를 검토하고 유지 설정을 재확인합니다.
4. 서드파티 런처를 쓰면 시스템 런처로 바꿔 테스트합니다.
5. 사용자 지정 테마를 쓰면 기본 시스템 테마로 바꿔 테스트합니다.
6. 휴대폰을 재시작합니다.
7. 다른 런처로 시도해 런처별 문제를 배제합니다.
