## 릴리스 로그

**✨기능**

1. 다중 해금 조건 업적 지원
2. 업적 세부 정보에서 조건 세부 정보 및 진행률 확인 지원
3. 작업 태그
4. 마감일 없는 반복 작업
5. 품절 또는 구매 비활성화 아이템 숨기기
6. 아이템의 경험치 감소 효과 설정 시 사용 제한 선택 가능
7. 인벤토리 페이지에서 다중 선택, 전체 선택, 일괄 반납 지원
8. 기본 작업 목록에서 보관 작업 지원
9. 설정, Q&A, 상점 도구 모음 등 페이지 재디자인 및 목록 페이지 추가
10. 일부 App 내 아이콘 재디자인(기본 작업 카드 아이콘, 코인, 경험치, 업적 아이콘)
11. 이미지 저장을 외부 App 전용 경로로 이동하여 실수로 파일이 삭제되는 것 방지

**♻️개선**

1. 설정 페이지에 [호환성 설정] 문서 링크 추가
2. 포모도로 카운트다운 — 초기화 작업에 확인 대화상자 추가
3. 작업 동결 설명 추가
4. 업적 하위 카테고리 설명 추가
5. 오프라인 모드에서 프로필 편집 페이지에 오프라인 모드 종료 버튼 추가
6. 무제한(negative) 작업 통계 최적화, 당일 포기 횟수 표시 및 업적 추적 지원
7. App 시작 속도 최적화
8. 업적 아이콘에서 큰 이미지 보기 지원
9. 임의 작업에 대한 좋아요(받음) 통계 추가
10. 검색 상호작용 통합 최적화
11. 아이템 선택 시 빈 목록으로 전환하면 로딩 대신 빈 레이아웃 표시
12. 큰 이미지 보기 페이지가 현재 테마 색상 설정에 맞게 조정
13. 선택된 아이템 및 작업 팝업 창 높이 변경 시 애니메이션 효과 최적화
14. 백업 설정에서 "로컬 데이터 삭제"가 미디어 파일 삭제도 지원
15. 사진 촬영 임시 파일의 저장 및 삭제 로직 통합
16. 기본 아이템 아이콘과 로드 실패 아이콘 구분
17. 이제 작업의 독립적인 plenty 설정이 기본으로 활성화
18. 감정 페이지의 새로고침, 애니메이션 로직 및 로딩 속도 최적화
19. 일부 세부 정보 팝업에 "선택" 바로가기 버튼 추가
20. 고급 설정 페이지의 "효과음" 및 "진동" 주 스위치를 끄면 포모도로 설정에도 해당 안내 표시
21. 새 업적 및 하위 카테고리 정렬 최적화
22. 기본 라이브러리 및 의존성 업그레이드
23. 업적 진행률 계산 방식 및 속도 최적화
24. "목표(반복) 횟수" 계산 방식을 기록 통계 개선에 맞게 개선하여 세부 정보의 횟수와 일치
25. 코인 수 및 목표 반복 횟수 입력 시 현재 값 전체 자동 선택
27. WebDAV 설정이 비정상일 때 오류 프롬프트 최적화
28. Google Drive 백업이 비정상일 때 오류 프롬프트 최적화
29. 세부 정보 페이지에서 작업 이름 선택 지원

**🐛수정**

1. 작업이 반복 로직을 실행한 후 설정된 count가 작업 보상에 영향을 주는 문제 수정
2. 상점 페이지 정렬 및 그룹화 문제 수정
3. 일부 경우 임의 작업에서 페이지 위아래 이동이 비정상인 문제 수정
4. 일부 경우 양의 타이밍 사용 후 상태 페이지의 포모도로 통계가 부정확한 문제 수정
5. 팀 작업의 반복 로직이 count 작업 유형 설정을 잃는 문제 수정
6. 업적 조건 관련 작업 선택 시 포모도로에 선택된 작업이 강조 표시되는 문제 수정
7. 감정 사진이 독립적으로 저장되지 않고 표시 문제가 있는 문제 수정
8. 로그인 실패 시 실패 프롬프트가 자주 팝업될 수 있는 문제 수정
9. 새 작업, 팀, 하위 작업의 일부 특수 입력란은 키보드 입력을 허용하지 않아야 하며, 그렇지 않으면 App이 충돌할 수 있음
10. App 위젯에서 무제한 아이템 완료 횟수 계산 방식을 App 내와 일치하도록 최적화
11. ATM이 이자율을 조정한 후 누적 시간과 조정된 이자율을 기준으로 이자가 계산될 수 있는 문제 수정
12. 동결된 작업이 스마트 목록에 여전히 표시될 수 있는 문제 수정
13. 특정 객체(작업, 상점 아이템) 선택 시 선택 표시줄에 가려진 작업 버튼을 여전히 탭할 수 있는 문제 최적화
14. 아이템 색상 변경 시 UI가 즉시 새로고침되지 않는 문제 수정 15.이자율을 낮게 유지한 후 갑자기 높은 이자율 설정 시(1골드 획득 실패) 거대한 이자를 받을 수 있는 문제 수정
16. 검색 표시줄을 연 상태에서 아이템 사용 후 작업 완료 시 검색 상자가 팝업되는 문제 수정
18. 무한 작업 이름 변경 후 당일 App 내 완료 횟수가 위젯과 일치하지 않을 수 있는 문제 수정
19. 무제한 작업 완료 시 이상한 애니메이션 수정
20. 작업 복사 시 작업 배경이 복사되지 않는 문제 수정
21. 일부 경우 업적 조건이 완료되었지만 업적을 해금할 수 없는 문제 수정
22. 날짜 간격 계산 예외 문제 수정(여러 로직에 잠재적 영향)
23. 작업 세부 정보 페이지에서 감정이 자동으로 필터링되지 않는 문제 수정

## 다음은?

다음 릴리스에서 더 흔한 피드백 요구 사항을 계속 해결할 계획입니다.

예를 들어, 야간 모드의 테마 색상 적용, 하위 작업 보상 경험치 및 아이템, 아이템 구매 시 속성 레벨 제한 추가 등입니다.

동시에 Google Calendar 통합 가능성도 가까운 시일 내에 조사할 예정입니다(하지만 이 기능은 출시까지 2~3개 버전이 더 필요할 수 있습니다).

여가 시간에 독립적으로 개발하고 있으므로, 위 내용은 근기 목표일 뿐이며 해당 출시 시점은 보장되지 않습니다.

Reddit 또는 Twitter(@AppLifeup)를 팔로우하면 더 많은 정보를 확인할 수 있습니다.

질문이나 피드백이 있으면 언제든지 이메일로 문의해 주세요.

Reddit에서 토론하고 구축해 주신 모든 분께도 감사드립니다. 앞으로 더 많은 영어 글도 게시하도록 노력하겠습니다.
