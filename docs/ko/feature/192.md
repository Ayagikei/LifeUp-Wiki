## 📱Android App 업데이트

### 🏆새로 디자인된 통계

![image-20230716005706966](_media/192/image-20230716005706966.png)

![image-20230716005752274](_media/192/image-20230716005752274.png)

통계와 데이터 검토는 생산성 향상의 중요한 단계일 뿐 아니라 영감과 피드백의 원천이기도 합니다.

노력을 되돌아보면 데이터로 진행과 업적을 확인하고, 문제와 개선 영역도 파악할 수 있습니다.

이를 위해 [Statistics 2.0]을 출시했으며, 다양한 흥미로운 데이터 인사이트를 제공합니다.

<br/>

#### ❓사용 방법?

![image-20230716021918105](_media/192/image-20230716021918105.png)

새 통계에 접근하려면 v1.92.0으로 업그레이드한 뒤 [통계] 페이지로 이동하고, 상단의 [새 통계 보기] 버튼을 탭하세요.

<br/>

#### 📊통계 항목

![image-20230716005738662](_media/192/image-20230716005738662.png)

Statistics 2.0은 다양한 모듈에 대한 데이터 분석을 제공합니다: 포모도로에서 집중 작업 비율부터 하루 평균 포모도로 수, 속성의 일일 변화, 아이템 구매 기록, 작업 완료 상태 등.

<br/>

#### ⏰시간 필터

![image-20230716005914025](_media/192/image-20230716005914025.png)

**유연한** 시간 범위 필터링을 지원하며, 하루, 주, 월, 연 또는 사용자 지정 시간 범위의 데이터를 쉽게 볼 수 있습니다.

LifeUp은 여러분에게 맞춰져야 합니다. 연말까지 연간 요약을 기다릴 필요도, 매년 연간 요약을 잃을 걱정도 없습니다.

LifeUp에서는 **과거 연도 연간 요약**에 언제든 접근할 수 있습니다. 2022년 연간 요약 데이터가 궁금하신가요~ 빨리 업데이트하고 사용해 보세요!

<br/>

#### 👥공유

![image-20230716005902342](_media/192/image-20230716005902342.png)

커뮤니티와 LifeUp 여정을 공유해 주세요!

공유하고 싶은 데이터 통계 카드를 길게 누르면 공유 카드를 만들고, 한 번의 탭으로 다른 App에 공유할 수 있습니다.

## 🖥️데스크톱

### ✨자동 연결

![image-20230716020204259](_media/192/image-20230716020204259.png)

![image-20230716020210438](_media/192/image-20230716020210438.png)


사용자 피드백에 따르면 IP 입력이 데스크톱 버전 사용을 방해하는 주요 요인입니다.

이번 업데이트는 LifeUp Cloud Server IP 자동 감지 기능을 가져옵니다.

<br/>

이 기능 사용 전제 조건:

- LifeUp Cloud v1.3.0 다운로드(Google Play 업데이트 또는 GitHub Releases에서 받을 수 있음).

데스크톱 버전에서 해당 IP 주소를 자동 감지할 수 있으며, 더 이상 수동으로 입력할 필요가 없습니다.

> 테스트 결과, 이 기능은 현재 주로 Windows 측에서 검증되었습니다.
>
> macOS 측은 아직 자동 감지를 지원하지 않을 수 있습니다.

### 🚀**감정을 markdown으로 내보내기**

![image-20230716020241251](_media/192/image-20230716020241251.png)

![image-20230716020226764](_media/192/image-20230716020226764.png)

데스크톱 버전에서 감정을 markdown 형식으로 내보낼 수 있습니다.

여러 방식으로 그룹화하여 내보낼 수 있으며, 감정에는 완전한 이미지 첨부도 포함됩니다.

markdown 형식으로 **서드파티 도구**를 쉽게 사용해 pdf, word 등 다른 형식으로 다시 렌더링하고 변환할 수 있습니다.

### **✏️작업 추가**

![image-20230716020407513](_media/192/image-20230716020407513.png)

이전에 구축한 API 기능의 도움으로 데스크톱 버전에서 간단한 작업 생성을 지원합니다.

현재 설정은 App의 모든 옵션을 아직 다루지 못하지만, 간단한 작업 생성에는 충분합니다.

후속 버전에서도 작업 생성 옵션을 계속 확장하고 작업 편집 등을 지원할 예정입니다.
