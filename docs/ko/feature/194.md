## 1. ✅다중 아이템 보상

![image-20240422223851277](_media/194/image-20240422223851277.png)

## 2. 🔧인벤토리 위젯

![widget_inventory_large_preview](_media/194/widget_inventory_large_preview.png)

이번 버전은 두 가지 크기의 인벤토리 위젯을 도입합니다.

이제 데스크톱에서 인벤토리 아이템을 직접 보고 빠르게 사용할 수 있습니다.

<br/>

### 🚀 최적화 및 문제 해결

상점 위젯을 몇 버전 전에 출시했지만, 점차 충돌 등 문제가 발생했습니다.

예를 들어 위젯 시스템 전송 한도로 아이템이 너무 많으면 App이 충돌하거나, 목록 전환 문제, 커스텀 이미지 로드 실패 등이 있었습니다.

이번 버전에서 적절한 해결책을 찾았습니다. 이제 상점 및 인벤토리 위젯이 많은 수의 아이템을 표시할 수 있으며, 거의 1000개 아이템의 상점 위젯도 테스트하여 정상 작동 및 로드를 확인했습니다(물론 권장하지는 않습니다).

<br/>

### 📕사용 방법?

보통 시스템 데스크톱을 길게 눌러 위젯을 만들 수 있습니다.

Xiaomi 또는 Redmi(MIUI/HyperOS) 기기를 사용 중이라면 MIUI/HyperOS에서 위젯 추가가 다소 숨겨져 있으니, 호환성 설정 문서에서 위젯 추가 방법을 확인하세요.

## 3. ✨더 많은 기능

**UI 테마**

![image-20240422223925926](_media/194/image-20240422223925926.png)

1. 커스텀(작업, 아이템 텍스트) 색상에 더 많은 사전 설정 값 포함
2. Android 14 단색 적응형 아이콘 기능 적응
3. 더 많은 언어 적응 추가(Google Play 버전)

**업적**

![image-20240422223959899](_media/194/image-20240422223959899.png)

1. 수령하지 않은 보상이 있는 업적이 있으면 업적 목록에 작은 빨간 점 표시

**작업**

![image-20240422224026331](_media/194/image-20240422224026331.png)

1. 벌칙 작업의 하위 작업이 이제 벌칙 로직을 올바르게 실행
2. "스마트 시간대 관리" 추가, 시차가 있는 업무에 관여한다면 LifeUp이 시간대 변경 자동 감지 및 전역 시간 조정 지원
3. 세부 정보 페이지의 통계 기준이 마지막 선택을 기억하며, 일부 시나리오의 기본값 최적화
4. "내" 페이지의 연속 작업 완료 일수 grace 처리 최적화, 하루 완료를 잊어도 따라잡기로 연속 기록 유지 가능

**속성**

![image-20240422224041201](_media/194/image-20240422224041201.png)

1. 경험치 기록 삭제 지원
2. 개별 속성의 경험치 초기화 지원

**위젯**

1. 상점 또는 인벤토리 위젯의 빈 공간 클릭 시 마지막 목록이 아닌 위젯이 가리키는 목록으로 바로 이동
2. 작업 위젯이 count 작업의 진행률 표시

**API**

1. 포모도로 기록 편집 API 추가
2. 작업 완료 API가 벌칙 작업도 올바르게 처리
3. 작업 완료 API가 count 작업 처리도 지원(`count` 매개변수 추가)
4. 작업 완료 API가 보상 계수 매개변수 지원
5. 아이템 조정 API가 아이템 목록 id 변경 지원
6. 아이템 생성·조정 API가 정렬 기준 매개변수 지원
7. 점프 API가 아이템 사용 팝업으로 점프 지원
8. `itemId` → `item_id` 등 일부 매개변수 정의 통일
9. 스톱워치 시작, 일시 정지, 종료 브로드캐스트 알림 추가
10. 아이템 조정 API의 `title_color_string`이 빈 문자열 전달로 기본값 복원 지원
11. 작업 완료 브로드캐스트에 목록 id 포함
12. 상자 열기, 합성도 아이템 사용 브로드캐스트 트리거

### ♻️최적화

1. 작업 추가 또는 편집 시 속성이 선택되지 않고 경험치가 입력된 경우 경고 포함
2. 업로드 재시도 기록 최적화
3. 커스텀 레벨 페이지의 제목 표시 및 입력 제한 최적화
4. 많이 반복된 작업 취소의 성능 및 타이밍 문제 최적화
5. 아이템 사용 팝업, 달력 인터페이스 로직 등 리팩터링
6. 작업 알림 관련 로직 최적화, 삭제되거나 이전 데이터의 알림이 다시 발행되지 않도록 보장
7. 백업 인터페이스의 대기 문구 최적화
8. 커스텀 속성 페이지에서 선택한 이미지도 기록 선택에 추가
9. 포모도로 기록 편집 시 올바른 수의 포모도로를 수정(증가 또는 감소) 시도

### 🐛버그 수정

1. 재구조화 후 통계 및 백업 관련 시스템 업적이 정상 트리거되지 않는 문제 수정
2. random API 및 toast API 위젯이 기본 toast와 잠재적 충돌 수정
3. 위젯에서 진입 시 일부 시나리오에서 작업 세부 정보가 새로고침되지 않는 문제 수정
4. 일부 특수 상황에서 다중 상자 열기 오류 가능성 수정(선제적으로 아이템 인벤토리 소진)
5. 하위 작업 없는 작업 편집 후 새 하위 작업 추가 시 세부 정보 페이지에 하위 작업이 표시되지 않는 문제 수정
6. 코인 보상 편집이 불가능한 일부 특수 경우 수정
7. 팀 아이템 수령이 작동하지 않을 수 있는 일부 경우 수정
8. 일부 하단 팝업의 MD2 스타일 이상 수정
9. 포모도로 타이머의 잠재적 잘못된 추가 시간 값 수정
10. 경험치 변경 위젯의 색상 막대가 표시되지 않을 수 있는 문제 수정
11. 진행 중 달력에 일부 작업이 올바르게 표시되지 않는 문제 수정
12. 기록, 감정 페이지의 일부 목록 로딩 문제 수정
13. 연속으로 작업 완료 API를 두 번 빠르게 호출해도 두 번 연속 완료가 허용되지 않던 문제 수정
