# *LifeUp Lite* 데이터 삭제 요청

## 1. 데이터 저장 및 삭제

LifeUp Lite는 LifeUp의 무료 버전으로, 주로 사용자 기기에 데이터를 저장합니다. 개인정보와 자율성을 소중히 여깁니다.

LifeUp Lite에서는 사용자 계정이 생성되지 않으므로 모든 개인 데이터는 기기에 로컬로 저장됩니다.

**이 데이터를 삭제하려면 기기에서 LifeUp Lite App을 제거하면 됩니다. 제거 시 로컬에 저장된 모든 데이터가 영구적으로 삭제됩니다.**

## 2. 제3자 서비스

LifeUp Lite는 기능 및 광고 목적으로 Firebase, Admob 등 제3자 서비스와 연동됩니다.

이 서비스가 수집하는 데이터에는 신원과 연결된 개인정보가 포함되지 않으며 각 서비스의 개인정보 처리방침에 따라 사용됩니다.

이 데이터는 해당 서비스 정책에 따라 일정 기간 후 자동 삭제됩니다.

## 3. 데이터 삭제 지원

데이터 삭제에 대한 도움이나 질문이 있으면 lifeup@ulives.io 로 문의해 주세요.

데이터 개인정보 관련 문의나 우려에 대해 지원하며 필요 시 절차를 안내합니다.

## 4. 준수 및 업데이트

최신 규정 및 업계 표준 준수를 위해 지속적으로 관행을 검토하고 업데이트합니다. 데이터 관리 및 삭제 절차 변경 시 본 개인정보 처리방침 해당 섹션이 필요에 따라 업데이트됩니다.
