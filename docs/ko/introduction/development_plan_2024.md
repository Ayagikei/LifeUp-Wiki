### II. 2023년 회고

LifeUp의 반아마추어·반여가 개발 여정은 5주년을 지나 6년째에 접어들었습니다. Android 저장소만 수천 번 가까운 코드 커밋과 수백 개 버전을 출시했습니다.

<br/>

2022년 10월에 제안한 개발 계획은 LifeUp 기능 체계 심화에 초점을 맞췄지만, 환경 변화로 여정 중 많은 장애와 어려움이 있었습니다.

#### 1.1 환경

대표적인 예:

- 일부 성에서 "사기 방지" 오신고 영향, 이의 제기 채널 없이 여러 차례 해결. 최근에는 산둥에서 다시 오신고 이슈가 있었고 아직 이의·재현 경로를 찾지 못함.
- 중국 국내 Android App 시장 심사 기준이 계층적으로 강화, 시장·인원마다 기준 불일치, 심사자 전문성 부족.
  - 일부 App 시장은 변경 없는 부분으로도 자주 심사 거절.
  - 한 V App 시장은 "개인정보 준수"를 이유로 LifeUp 거의 거절. 시장은 App이 [모든 파일 읽기 권한] 또는 [모든 사진 읽기 권한]을 신청하고 설명을 요구해 사용자가 앨범에서 이미지를 선택하게 함. LifeUp은 더 개인정보 보호적인 방식을 쓰며 그런 권한이 필요 없고 사용자 파일을 직접 읽지 않음. 대신 시스템 내장 앨범 App으로 이동해 사용자가 선택한 이미지만 받아 최대한 개인정보 보호.
    그러나 심사자는 이 모범 사례에 익숙하지 않아 고객 지원과 며칠간 소통 후 승인.

<br/>

환경 영향을 줄이기 위해:

App 내 업데이트 메커니즘을 강화하고 시장 심사 제출 빈도를 줄였습니다.

국내 버전은 App 내 업데이트를 지원하며 stable 또는 beta 채널 전환 가능.

![Screenshot_2023-12-09-15-45-33-18_50eeeb96828cbaa](_media/development_plan_2024/Screenshot_2023-12-09-15-45-33-18_50eeeb96828cbaa.jpg)

공식 웹사이트(https://lifeupapp.fun/en/index.html)도 대체 다운로드 채널로 업데이트.

![image-20231209154445462](_media/development_plan_2024/image-20231209154445462.png)

웹사이트로 App 다운로드·설치를 더 편하게 하여 시장 심사 위험과 지연 회피.

App 내 네트워크 요청에도 백업 채널을 추가해 일부 성 오신고로 인한 접근 문제 완화·방지.

<br/>

심사 기준이 점점 엄격해지고 국내 Android 시장의 다른 독립 개발자들이 겪는 장애를 보면,

독립 개발자에게 국내 Android 플랫폼은 더 이상 이상적인 첫 출시 대상이 아닙니다.

국내 Android가 가장 엄격한 자격 요건과 가장 복잡하고 **변하기 쉬운** 심사 기준을 갖기 때문입니다.

> 아이러니하게도 동시에 일부 저품질 카피 App은 쉽게 등록되고 "수동 재검사 통과" 표시.

이것이 샤오홍슈에서 본 많은 독립 개발자 작품이 iOS 버전만 있는 이유일 수 있습니다.

Google Play와 App Store가 여전히 첫 선택입니다.

?> 국내 Android 플랫폼을 고수하는 독립 개발자와 소규모 팀에 더 관심을 갖고 응원해 주세요~

<br/>

따라서 2024년에는:

- 이전 계획의 미완 부분을 이 기간으로 이전, 예: 캘린더 연동, 반복형 업적, 기본 기능, 데이터 시스템 등.
- 멀티 플랫폼 개발이 중요한 목표, 두 방향 포함 가능:
  - Flutter로 LifeUp 복제(인력 제한으로 백엔드 동료 샤오샤오가 진행)
  - KMP(Kotlin Multiplatform)로 더 많은 가능성 탐색

#### 1.2 국내 사용자 성장

또한 LifeUp은 2023년 중국 App 시장에서 상당한 사용자 성장. 모두의 지원에 감사!

- 수동 교환 코드 발급 시간을 줄이고 개발에 더 집중: 2023년에 자동 결제(WeChat, Alipay) 연동 및 WeChat 로그인 지원.
  - 많은 시간 확보.

- 2023년 Qzone에서 사용자 확산이 서버를 며칠간 다운.
- WeChat 공식 계정, 샤오홍슈, 빌리빌리 등 운영 시도로 LifeUp 업데이트와 창의적 사용법 홍보.

- 다른 독립 개발자와 논의 결과 대부분 비슷한 어려움을 겪고 특정 IM·SNS 채널을 닫기로 선택. 깊이 공감.
  - 대기업에는 보통 전담 고객 지원팀이나 봇이 많은 문의를 처리해 개발자에게 구체적 요구·문제 피드백으로 전달.
  - **독립 개발자는 일반적으로 고객 지원·운영을 직접 부담; 불합리한 사용자 대응이 이 독립 개발자의 개발 시간 100%를 소모해 결국 개발자, 제품, 핵심 사용자에게 영향.**
  - 따라서 이메일 등으로 피드백을 권장하는 경향 증가.

<br/>

따라서 2024년에는:

- 반복 상담에 투입하는 인력을 계속 줄이고 문서·FAQ 개선. 상담이 있어도 이메일, QQ 채널 등으로 통일 처리.
- 소량의 SNS 운영 시도.

#### 1.3 해외 사용자 성장

2022년 초 Google Play Pass 가입 후 사용자 성장 파도.

그러나 오래 지속되지 않았고 2022년 중반부터 사용자 성장이 크게 감소, 개선 징후 없음.

LifeUp은 일회성 구매 App이라 사용자 성장이 매우 중요하며, 계속 운영하고 미래 전업 개발 기회를 갖는 토대.

성장 개선을 위해 많은 방법 시도:

![image-20231209154347665](_media/development_plan_2024/image-20231209154347665.png)

- 전문 디자이너 고용해 스토어 홍보 이미지 재디자인
- App 및 홍보 이미지 다국어 지원 개선
- App 설명 개선
- 시작하기 문서 개선
- 업데이트 빈도 증가
- ...

많은 방법을 실행하고 일부 지표를 개선했지만 안정적 성장기로 돌아가지 못함.

어쩔 수 없이 그대로 두었음.

<br/>

좋은 소식은 2023년 말에 다소 개선된 것 같음.

<br/>

따라서 2024년에는:

- 국제화 구축 개선(문서, App 내 언어 지원 등).

#### 1.4 품질 관리

LifeUp은 혼자 개발·테스트하는 오프라인 도구 App이라 심각한 충돌 회피가 특히 중요.

2023년 버전 반복 과정은 이전보다 길었고, 충분한 beta 테스트 시간을 확보해 철저히 준비.

![image-20231209154314651](_media/development_plan_2024/image-20231209154314651.png)

이 조치는 대규모 심각 충돌 발생을 효과적으로 막는 것 같음.

그러나 각 버전 업데이트마다 여전히 문제가 불가피하며, 일부는 핵심 경로.

따라서 LifeUp 품질 관리를 계속 개선하고, 안정성을 가장 중요한 지표로(특히 점점 엄격한 환경과 심사 도전 하에서).

<br/>

따라서 2024년에는:

- 품질 관리 강화.

#### 1.5 기능 심화

3주년 글에서 언급했듯 LifeUp은 점진적으로 탐색·성장한 App.

상점, 사용자 지정 업적, API 같은 기능은 초기 계획에 없었지만 업데이트와 피드백으로 점차 개발·추가.

그러나 문제도 도입:

- 일부 모듈의 기획 세부가 거침.
  - 예: 아이템 보상은 처음 단일 보상만 고려.
  - 속성 등 시스템도 처음에는 사용자 지정 미고려, 점진적 리팩터링으로만 추가·삭제·사용자 지정 레벨 등 지원.
  - 속성 보상/벌칙 팝업과 기록 표시가 최대 3개만 지원 등 비슷한 문제 많음.
- 새로 추가된 모듈은 App 전체 분석·기획 부족.

3주년 글 방향을 계속 따라 기존 기능 모듈을 심화하고 pain point 해결, 신규 기능 모듈 추구 지양.

예: 아이템 보상 직접 다중 선택 지원, 백업 메커니즘 개선, 알림 최적화, 위젯 완성 등.

#### 1.6 API와 확장성

위에서 언급했듯 더 이상 신규 기능 모듈 도입 계획 없음.

그러나 App 확장 요구는 분명 존재.

2023년에 API 기능 도입.

LifeUp 핵심을 기반 역량으로 제공.

프로그래밍을 몰라도 Tasker/MacroDroid 같은 자동화 도구로 기능 확장, 자동화 역량 달성.

대표 예:

- NFC, QR 코드로 작업 완료
- 기상 시 자동 체크인
- 사용자 지정 위젯
- 기타...

프로그래밍을 알면 더 많은 플레이나 App까지 확장 가능.

![img](_media/development_plan_2024/desktop.png)

API 기반 간단한 데스크톱 버전도 개발(오픈 소스).

여러 버전 API 확장 후에도 많은 역량 부족.

예: "생각(thought)" 관련 작업 미지원, Content Provider로 데이터 업데이트 미지원 등.

2024년 API를 계속 확장해 App 모든 측면을 최대한 아우름.

> 현재 많은 사용자가 API를 개인용으로 쓰지만 공유 가능한 실행 제품은 아직 적음. API 생태계 구축을 위해 더 강한 API 역량 제공 필요.

#### 1.7 미래에 대해

위 문제와 환경 변화로 LifeUp 평생 멤버십 가격을 점진 조정(그래도 LifeUp 멤버십 가격은 대부분 다른 App보다 훨씬 낮음), 업데이트도 점차 멤버십 기능 제공 쪽으로 기울 것.

App은 궁극적으로 핵심 사용자를 위해 존재한다는 것을 점차 깨달음.

핵심 사용자 피드백과 지원이 App 개선에 반영되어 개발자와 사용자 공동 창작·선순환.

모두를 기쁘게 하려 하면 App은 코드 뭉치가 되고 핵심 사용자 요구에서 벗어나 개발자 수익과 동기 감소.

<br/>

위에서 KMP(Kotlin Multiplatform) 언급, 비교적 새로운 크로스 플랫폼 기술. 네이티브 역량 혼합 사용 가능.

LifeUp 개발 중 새 아이디어가 점차 생김. 그러나 모든 아이디어가 LifeUp에 구현되거나 적합하지는 않음.

예: UI 전면 교체, 상점 로직 대규모 변경 등은 기존 사용자 경험에 심각한 영향. 대규모 App 변경 실패 사례도 많이 봄.
