# *LifeUp Pro* 데이터 삭제 요청

## 1. LifeUp Pro에서의 데이터 삭제

LifeUp Pro 사용자는 App 내에서 독립적으로 데이터를 삭제할 수 있습니다.

LifeUp Pro는 주로 오프라인 App이므로 기기에서 직접 데이터를 관리할 수 있습니다.

데이터를 삭제하려면 다음 단계를 따르세요:

1. LifeUp Pro App에서 `설정` → `데이터 백업/복원/지우기`(`백업 / 복구`)를 연 다음 `데이터 삭제 및 계정 삭제`를 엽니다.
2. `경험치 데이터 지우기`, `코인 데이터 지우기`, `시스템 업적 데이터 제거`, `이력 데이터 삭제`, `로컬 데이터 삭제` 중에서 선택합니다.
3. 확인합니다. 경험치, 코인, 시스템 업적, 이력 삭제는 App을 열어 둔 채로 끝납니다. `로컬 데이터 삭제`는 15초 카운트다운 뒤 데이터베이스, 설정, 미디어를 지우고 App을 처음 설치한 상태로 되돌린 다음 다시 시작합니다. 먼저 직접 백업하세요.

**또는 기기에서 LifeUp Pro App을 제거하면 로컬에 저장된 모든 데이터도 삭제됩니다.**



## 2. LifeUp Pro 계정 삭제

LifeUp Pro에서 계정 삭제는 데이터 삭제와 별개의 절차입니다.

계정을 삭제하면 다음이 제거됩니다:

- 서버에 게시한 팀, 업데이트 등 공개 게시물.
- 계정에 연결된 닉네임 및 기타 개인정보.
- 계정에 연결된 OAuth 연동.

**LifeUp Pro 계정을 삭제하려면 앞서 설명한 단계를 따르세요:**

1. `설정` → `데이터 백업/복원/지우기`를 연 다음 `데이터 삭제 및 계정 삭제`를 엽니다.
2. `계정 삭제(원격 데이터)`를 탭합니다.
3. 30초 카운트다운 뒤에 확인하면 LifeUp 서버의 이 계정 데이터가 삭제됩니다. 먼저 직접 백업하세요. 기기의 작업 등 로컬 데이터는 남습니다.

<br/>

**LifeUp Pro App을 더 이상 사용하지 않지만 계정과 개인 데이터를 삭제하려면 [lifeup@ulives.io](mailto:lifeup@ulives.io) 로 문의해 주세요.**

계정 관련 필요한 정보를 제공해 주시면 삭제 절차를 안내합니다.

개인정보 보호를 위해 요청을 최대한 신중하고 기밀로 처리합니다.



## 3. 제3자 서비스

LifeUp Lite와 마찬가지로 LifeUp Pro는 향상된 기능을 위해 Firebase 등 제3자 서비스와 연동됩니다. 이 서비스가 수집하는 데이터는 개인을 식별할 수 없으며 해당 개인정보 처리방침에 따라 관리됩니다. 제3자 서비스 정책에 따라 일정 기간 후 자동 삭제 예정입니다.



## 4. 업데이트 및 준수

최신 개인정보 보호법 및 업계 표준에 맞추기 위해 지속적으로 관행을 모니터링하고 업데이트합니다. LifeUp Pro 사용자를 위한 데이터 관리 및 삭제 절차를 정확히 반영하도록 본 개인정보 처리방침 해당 섹션이 필요에 따라 수정됩니다.
