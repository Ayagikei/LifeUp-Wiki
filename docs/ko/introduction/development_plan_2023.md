# 2022/10 - 2023/12 개발 계획

!> 이는 만료된 개발 계획으로, 보관 및 참고 목적으로만 유지됩니다. 환경은 계속 변하며 계획도 그에 맞게 조정됩니다. 이 계획은 개발 방향을 대략적으로 보여 주지만 완전히 실행한다고 약속하지 않으며, 계획 밖 개발도 할 수 있습니다.

<br/>

LifeUp의 지난 몇 년 개발은 항상 새 기능 모듈을 개발하거나 기존 모듈에 새 기능을 추가하는 데 집중했습니다.

오늘날 LifeUp의 기능 모듈은 자체적으로 일관된 폭은 충분하지만 깊이는 부족하다고 봅니다.

따라서 다음 개발 목표는 기능 깊이에 맞춰 기존 사용 가능한 모듈을 지속적으로 개선하고 실용성(캘린더 연동, 위젯, 통계)을 높이는 것입니다.

또 API 기능을 지속적으로 확장해 외부 기능을 API로 충분히 확장할 수 있게 합니다.
추가로 데이터 시스템을 개선하고 Flutter로 크로스 플랫폼 버전 개발을 탐색합니다.

<br/>

- **2023/01/26**
